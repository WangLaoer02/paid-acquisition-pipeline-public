# 部署与依赖

仅首次安装、迁移或版本故障时读取。

业务方法在当前Skill入口维护；项目状态和采用来自唯一Sheet；运行工具与正式规则由飞书工作流中心的当前发布及固定执行副本锁定。Skill入口版本不是规则发布号。已有工作区的context负责核对发布与安装身份，不以本地最高版本号猜当前发布。

本目录的 `references/rules`、`references/workspace-contract` 和 `scripts/deploy_workspace.py` 是保留的兼容部署快照，其版本由包内manifest决定，可能早于当前发布；不是当前发布安装入口。该脚本只能向空目录部署其自带快照，不迁移登录、数据库或项目状态；不要用它覆盖现有工作区或宣称升级到当前规则。首次正式接入从工作流中心的当前发布标记定位安装包，再使用该包的 `paid-skit-progressive-setup`。共享Skill目录中的安装器可能是旧版本；它的verify仅证明自带文件完整，不能代替与当前发布标记比对。作者候选、固定副本与发布包不能互相覆盖来消除版本错误。

| 依赖 | 何时需要 | 迁移边界 |
|---|---|---|
| Python 3、当前节点脚本及24节点规则 | 读取项目节点 | 规则与工具同版安装；保留旧名兼容入口 |
| 飞书CLI及真实项目绑定 | 在线context／授权范围内写回 | 在目标机器核登录和Sheet身份；不复制历史绑定或凭据 |
| seedance-douyin-video、requests、FFmpeg／ffprobe | 新原片采集／解码；ASR另按其配置 | 原片按作品ID复用；Chrome和ASR服务是主机能力，不随文档安装 |
| seedance-prompts及当前专项 | 当前稿需要该方法 | 普通提示词不加载所有专项；独立方法按已安装Skill目录定位 |
| naruto-favoritism-skit-generator | 偏心／双标／踩捧 | 按当前节点接口与版本范围核对；部署不覆盖独立Skill |
| 荣耀或当前指定生成工具 | 已授权生成 | 实时模型、当前输入、账号、费用和提交守卫单独核验 |
| Premiere及本机桥、FFmpeg | A原生导出／A+B接片 | 目标机器核应用版本与桥；不以文件存在代替原生导出 |
| 荣耀HTTP上传工具 | 已授权上传 | 当前合同、防重放和原job恢复；不由Skill安装获得上传授权 |
| Seedance工作台 | 用户要求记录／已选用／排队任务 | 可选；代码可打包，SQLite、媒体、服务与登录需各自配置，不能用它替代项目Sheet |

本地修订与测试包只能用于方法阅读和隔离验证。后续正式发布仍沿原维护机制；未发布内容不解锁业务动作。
