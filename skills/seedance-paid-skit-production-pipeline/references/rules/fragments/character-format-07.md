## 06 头部保护与验收门槛
用户明确授权替代全身依据要求时，可选“多原图联合重建”方法。本批时髦精美美于2026-10-05获授权：至少两张同一作者、同一时期真实体型原图核对可见部位，先生成一张未验收的正视校准候选，其余造型直接引用它、真实脸部及各套原图；校准图直接绑定全部共同原始依据。每次实际参考最多五张，保留完整生成绑定。真人身高未知时留空，帽或头巾下头顶、遮挡肩位写明为估计，鞋袜与隐藏剪裁推测分别记录。检查面部及完整头脚，用已披露的输出地标比较比例，本批差异上限1.5%；这只是候选内部一致性检查，不能认证真实骨架或用户美术验收。下方原八点及0.5%条件保留为严格模式，不阻止已明确授权的替代方法。
同身份多造型先核验公开作者、作品与角色身份；共用脸部与全身体型锚点，每套直接使用共同锚点及本套原始服装帧，不串行接力定义下一套身份。只有母版请求时先完成指定数量的标准正视，不默认扩展三视图、动作或拆解。
参考不足时主动补采：继续从同一已核验博主的公开作品列表筛选其他作品，增加视频下载和抽帧；接近合格的站姿片段加密抽帧，不默认要求用户另找链接。图文作品读取原图，动态照片核对实际 MP4 与原图；用作品编号及文件校验值去重，记录真实覆盖范围。分页重复返回同一游标或编号时，记录未取得后续页，不能算新增覆盖。补采不改监控基线、pending 或 ack，不恢复已取消的批量收录。需要账号时先复用用户已登录的现有浏览器会话；用户要求不新开浏览器时，不启动独立浏览器或新配置。控制连接超时不能当成账号未登录，不据此要求重新登录。可用路线实测遇到登录、权限、网络或接口限制时，记录具体阻塞；不搬运浏览器凭据，也不降低身份与体型门槛。
图文原图按 raw_photo 记录作品编号、公开作品页、照片序号、文件校验值及作品归属核验，不伪记视频时间点，不收头像、页脚或推荐区图片。照片作为全身体型锚点时同样须满足完整头脚、站姿、平视弱透视与真实像素测量。
多人同框先逐人核对目标角色的位置、发型与可见衣物，不混入旁人的下装、鞋或配饰。同一图文含多套造型时，按照片序号分别绑定；颜色与衣物结构以实际图像为准，遮挡部位保留未知，各原图分别记录具体限制。共同脸部与全身体型依据取同一时期，跨年造型来源只承担衣物参考，不混合成长前后的身体测量基准。
每套记录生成前计划输入和每张输出实际输入的路径、校验值、来源作品及时间点、精确提示词。记录头颅顶、下巴、肩、腰、髋、膝、踝、不含鞋跟足底的实际像素 y 坐标，以 (y - 头颅顶) / (足底 - 头颅顶) 归一化；不能按画布高度比较比例。逐张独立检查面部结构与头部噪点，比例误差超过 0.5% 回共同锚点修订。真实身高无来源留空，肤色打底保留不透明服装覆盖。生成前及交付前运行本地 `character_consistency_gate.py`；检查器核对记录与文件，不能独立认证人工记录或代替视觉检查与用户美术验收。
1. 建立“真实来源 → 共同身份与体型参考 → 各套干净穿衣正视 → 三视/特写/拆解并列派生”关系；合格表情特写只作对应动作的表演参考，每张仍绑定真实身份/体型/本套衣物。习惯站姿另列角色级共用参考，不改标准三视的中性测量站姿；失败版不连续承担身份或纹理来源。
2. 服装、身体或材质修改合并写明，保护头部区域；有蒙版则限定区域，无蒙版则明确不能保证像素不变，并独立验收头部。
3. 同尺度核对头部轮廓、眼鼻嘴、耳朵与发饰、噪点、重复毛纹、锐化伪影；异常版本禁止继续派生身份。
4. 检查三视图比例、服装层次/领口图案、配件数量、爪套结构、材质/贴体、原始依据与推测边界。
5. 新制作的结构打底参考使用接近角色可见皮肤颜色的哑光、不透明贴体服，完整覆盖并保留衣物边界、不勒塑形，清楚展示有依据的自然轮廓、肢段与关节；遮挡处标推测，不冒充人体实测。实际造型中的白色衣物、原图和历史附件保留真实颜色。
6. 把入库成功、文件技术通过、用户美术验收分别记录；用户未确认不能标已验收。
