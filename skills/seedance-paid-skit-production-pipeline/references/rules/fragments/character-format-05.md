## 04 页面固定顺序
1. 角色预览：正文只放一张实际图片；候选或待修订状态简短明示。页面属性中的预览使用同一张图。
2. 角色图件：原生图库，按真实服装标签001、002、003、004、005等浏览；实际版本和V001/V002展示归类独立记录。正视、三视、特写及动作属于原服装，不另建套数或用途标签。
3. 原图来源：独立素材库，保存原始帧、实际选用时间点、来源视频链接与已验证的原生文件。原始视频未挂载时如实标明，不把链接称为视频附件。
4. 待同步图件：独立素材库，保存服装拆解、配件、基底等物件类图件和待拆分的混合总览，保留实际版本及原设计绑定。
5. 制作记录：放页末折叠区；先显示角色工作流正文，再保存批次执行记录与历史。角色工作流使用 Markdown SOP，写清角色来源、实际绑定、步骤的输入/操作/输出/通过条件/失败处理、质量标准和交付；详细共用方法引用标准 Skill。实际来源、提示词、生成与修订关系、历史配置及回执保留在原 JSON/图件记录中，不能用执行日志代替可读流程。沿用一个角色一个唯一页面，不因整理流程恢复已取消制作。
主页面不再出现“执行核对”栏目、13段素材章节、空白栏目、占位符、散落的哈希或调用过程。质量问题放入各图件的“审查状态、问题与限制”，完整审查放制作记录。
原19种用途仍可作为制作清单保留，不能把19种用途、不同动作或历史版本计为19套角色设计。缺项在记录里注明未制作、未入库或不适用，不补虚构图，也不自动触发生成。
