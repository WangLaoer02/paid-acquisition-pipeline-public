# 状态、权限与恢复

唯一项目Sheet记录当前节点、素材及采用；state_bindings只定位真实对象，checkpoint只记录已观察的基线与待复验，不覆盖在线用户修改。
每次context/status仅读当前对象及依赖；冲突、身份变化、未知节点或不同发布版本停止受影响执行。无关项目阻塞不能阻塞当前对象的只读准备。
单边变更同步沿workflow_state；同步前全部目标回读并比较，双边冲突不覆盖。A回退复验关联B；单B只影响该版；素材回退复验其引用成片。前移保留未解决的revalidation_required。
模板检查与写回保护不删除：实际写入时由console_content/console_template完成。检查点只放实际节点、版本、产物、待验和下一步；技术／维护证据仍在既有位置。
费用／模型／账号／素材／审美／上传／广告发布均不互相授权。后台上传是独立专项，不增加24节点。跨会话和规则发布依本次授权，不继承旧会话编号或巡检周期。
