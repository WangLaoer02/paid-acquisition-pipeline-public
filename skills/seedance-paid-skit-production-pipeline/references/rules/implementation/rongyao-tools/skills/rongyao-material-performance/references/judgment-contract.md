# 分析与判断契约

下文500元、ROI1 9%、2日倍率1.9是工具缺省分析参数；本次用户/面板确认的阈值和输入契约优先，并记录来源。指标达标与正式效果标签分列，缺省参数不冒称永久业务标准。

## 聚合公式

- 项目总体花费、ROI和新付费优先读取后台CSV的`总计`行；该行不得再次计入素材明细求和。
- 角色、方向、关键词及新产素材使用明细行聚合；同时报告明细花费与后台总计的差额。
- 差额原因默认未知。没有接口说明或后台证据时，不得写成“不可拆分计划项”“四舍五入”或其他确定原因。
- 花费：素材行花费求和。
- 新付费数：素材行新付费数求和；称为“新付费数”，不擅自解释为去重人数。
- ROI1：`Σ(花费×ROI1)/Σ花费`。
- ROI2：`Σ(花费×ROI2)/Σ花费`。
- 2日倍率：`聚合ROI2/聚合ROI1`；ROI1为0时缺失。
- 单次付费成本：`花费/新付费数`；新付费数为0时缺失。
- 观察素材：单条花费达到500元。
- ROI1达标素材：观察素材中ROI1达到9%。

## 角色归属

1. 优先解析角色标签。
2. 标签为多个角色时分别计入，因此角色总和可超过项目总量。
3. 标签为空、Array、群角或不可识别时，用素材名回填。
4. 标签和名称都无法识别时归入“未识别”，不硬猜。
5. 标签与名称冲突时保存样本；主归属使用标签。

## 方向归属

- 同时匹配素材名、一类、二类。
- 一条素材允许属于多个方向，方向总和可超过项目总量。
- `AI`不能自动等于AI剧场；必须命中对应名称或二类标签。
- `一图流`、`700级`、`踩捧`、`抽卡`、`原生录屏`等独立统计，不能互相替代。

## 趋势判断

用户采用结束日留2天的口径且实际查询满足时，ROI1/ROI2按已成熟口径使用；ROI3及以后字段发生变化不等于ROI1/ROI2抓取失败。
