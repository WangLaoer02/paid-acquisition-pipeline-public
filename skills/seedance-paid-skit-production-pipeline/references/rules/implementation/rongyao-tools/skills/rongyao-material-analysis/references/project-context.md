# 项目背景

## 工作链路

用户是游戏信息流视频设计师，日常工作包括素材制作、审核、上传荣耀后台、复盘后台数据。

荣耀后台用于观察素材投放表现。素材复盘要把数据和创意结构连起来，判断哪些方向继续做、哪些方向暂停、哪些元素单独抽出复用。

## 项目目标

- 找出能消耗且能付费的素材。
- 找出可复用的角色、脚本、画面、版面和A/B段结构。
- 用数据验证方向，不用主观感受替代数据。
- 给周报写作层提供效果判断和有内容依据的制作建议，由写作层结合业务信息整理实际产出计划。

## 素材理解核心

素材判断不是只看 ROI。

完整判断应包含：

- 能不能消耗。
- 能不能付费或回本。
- 后续倍率能不能追。
- 对比上周是否变化。
- 标签是否集中在某类方向。
- 标志素材中的变量是否可复用。

## 人群理解

以下是制作时可验证的常见策略，不能由素材名或指标自动推定本次人群和因果：

- A段负责泛用户拓圈。
- B段负责筛选核心付费用户。
- IP角色吸引兴趣。
- 卡牌、阵容、培养、首充、福利承接付费。

## 与其他 Skill 的关系

- `rongyao-material-performance`：抓取并校验荣耀后台素材表现数据。
- `rongyao-weekly-report-writing`：组装带真实面板贴图的正式素材周报，沿用当前会话对目标与范围的有效写入授权。
- 本 Skill：解释数据、核对素材内容，输出专项判断与按需验证建议。
