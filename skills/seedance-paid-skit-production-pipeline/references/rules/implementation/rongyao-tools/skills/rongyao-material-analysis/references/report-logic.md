# 专项判断的证据组织

## 先固定能回答的问题

核对实际项目、投放周期、产出范围、快照时间、完整性和成熟度。周报调用方已传入周六至周五等业务周期时保留该周期，不用抓数工具的自然周缺省覆盖。上游失败、缺列或未返回完整范围时，保留缺口，不以本地历史样例补0。

新老素材按目标周期和历史身份拆分：产出日期、首次出现记录与素材 ID 一起核对；更新产出日期的历史素材仍属于老素材。投放明细只回答本次返回素材的表现；完整产出量以经确认的生产台账为准。

## 聚合与贡献

- 对“老素材支撑”“新素材接替”分别计算消耗贡献、付费贡献和有效贡献；分母、有效规则及重叠标签要明确。某组消耗占比高只支持消耗贡献结论。
- 对头部集中同时看头部贡献和其余素材表现。保留单条拉动与多条复现的差异，不用一个爆量样本替整个方向定性。

具体聚合与角色/方向归属沿用 [表现分析契约](../../rongyao-material-performance/references/judgment-contract.md)。效果类别按当前确认的互斥顺序去重；创意标签可重叠，其贡献不能直接相加为项目总量。

## 比较与判断

需要趋势时使用紧邻、等长、同项目、同筛选且成熟度可比的上一期。无可比基线时仍可描述当期结构，不写升降。先核对消耗变化，再判断付费量、成本、首日回本及后续回本各自变化；付费数增加和回本改善分别成立才分别表述。

选择代表素材用于解释贡献、变化或反例。名称只保留原文主体，前缀编号和明确尾缀可去除；角色纠错、剧情归类必须有来源确认。

## 内容假设与制作建议

指标事实和内容观察拆为独立 finding，并通过事实 ID 关联。画面只依据实际看过的视频或关键帧，台词依据逐字稿或用户提供内容；名称可以辅助匹配，不替代观看。关键帧没有覆盖的动作、声音和剧情保留未知。

创意判断允许提出尚未验证的解释，例如同一B段下两种A段的关系冲突可能影响吸量；前提是两种内容已被观察或由用户明确提供。写明假设与有效范围，不宣称已证明投放原因。新增创意使用 `generated_proposal`、`validated=false`。

需要实验建议时，选能区分竞争解释的实际变量；其余内容保持可比，并写要观察的结果。只要效果判断时 `next_test=null`。

## 交付核对

每项结论绑定来源事实 ID，结论范围与项目/日期一致，反例用于修正判断。缺少证据时缩小结论，并指出缺的字段或素材内容。需要下游结构化校验时使用现有 `rongyao-material-performance/scripts/evidence_contract.py` 的 `validate_finding(finding, facts)`；合规 finding 示例见 [examples.md](examples.md)。
