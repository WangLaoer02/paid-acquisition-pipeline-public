# 素材分类和标签

## 五大方向

### 攻略

定义：角色玩法引导，帮助用户少走弯路。

常见素材：

- 阵容推荐
- 开局别选/开局选谁
- 角色培养
- 首充角色选择
- 700级技能展示
- 新手误区

判断重点：

- 是否能筛出核心付费用户。
- B段是否承接付费。
- 纯B段是否吸量不足。
- A段是否解决前三秒和泛人群拓圈。
- 周报中优先概括为当周数据支持的攻略系列；付费原因拆解时再细分到具体承接段。

### 品宣类

定义：游戏卖点推广。

常见素材：

- 年度黑马
- 官方承诺
- 简单爽
- 王者风技能展示
- Q版跑图
- 多场景跑品宣

判断重点：

- 是否能吸引重度游戏用户。
- 是否爆R但难消耗。
- 是否可消耗但回本差。
- 是否需要增加引流开头。

### 原生录屏

定义：用真实或仿真实战画面提供沉浸感和可信度。

常见素材：

- 纯战斗展示
- 技能实录
- 角色替换战斗
- 8090玩家风格承接

判断重点：

- 是否增强可信度。
- 是否能接入品宣或攻略B段。
- 是否适合小批量替换测试。

### 福利

定义：送送送，强调资源、角色、等级奖励和白嫖体验。

常见素材：

- 首充6元
- 10级送
- X级送XX加XX
- T0五星忍者
- 海量资源

判断重点：

- 是否有真实付费。
- 老脚本是否复跑有效。
- 是否能结合新版面、新角色、新服节点。

### 小剧场

定义：画面钩子和剧情钩子，用剧情冲突提高播放。

常见素材：

- 开局别选佐助
- 兄弟背刺
- 爱人维护
- 热点热梗
- 意难平
- 抖音高赞剧本改编

判断重点：

- A段是否拓圈。
- 是否把泛人群导入B段核心付费筛选。
- 剧情是否同质化。
- 是否能和攻略、福利、品宣B段闭环。

## 单素材拆解字段

- 主推角色：素材主要推谁。
- IP代表：该角色是否承担IP吸引。
- 主分类卖点：攻略、品宣、原生录屏、福利、小剧场对应的核心卖点。
- 剧本钩子：完播理由。
- 画面钩子：前三秒画面理由。
- 制作关键词：画风、UI、战斗、福利界面、立绘、口播等。
- 素材策略：拓圈、筛选核心人群、提高付费、验证变量。
