# 指标与分类口径

## 阈值来源

表现抓取工具的缺省分析参数为观察消耗500元、ROI1 9%、2日倍率1.9。它们是 Skill 参数，不代表永久业务标准。按用户本次确认、当前面板或输入契约使用实际阈值，并保存来源；来源不明时只描述指标，不自行宣布“优质/有效”。

## 指标

- 消耗/花费：本次投放量级；零消耗时缺少评价投放付费表现的样本。
- 新付费数：本次统计的付费计数；不自动解释为去重人数。大于0表示有付费。
- ROI1：首日回本。低于本次首日标准时不写首日达标。
- ROI2：次日累计回本。后续增长和达到累计回本目标是两个判断。
- 2日倍率：ROI2相对ROI1的倍数；ROI1为0时不可推导。倍率高可以描述后续增长较快，实际是否补回须有累计目标。
- CTR：点击指标，不能单独证明消耗规模或回本；没有该字段时不猜点击原因。

后台原始倍率与推导倍率分列；缺失指标为 null，不补0。聚合公式见 [表现分析契约](../../rongyao-material-performance/references/judgment-contract.md)。

## 五类素材数量

| 数量 | 条件和适用范围 |
| --- | --- |
| 产出素材数 | 经确认台账中产出日期落在范围内的去重素材；投放明细统计只能称本次返回的新产素材数 |
| 有消耗素材数 | 本次明细中花费大于0 |
| 可观察素材数 | 单条花费达到本次观察线 |
| 有付费素材数 | 新付费数大于0，与观察线和ROI标准独立 |
| 有效素材数 | 达到本次确认的有效规则或命中经确认的效果分类；说明使用哪一种 |

五类数量分别计算，各比率写明分母。新产身份结合素材 ID、产出日期及历史记录核对，历史素材日期更新不算当期新产。名称前缀只作辅助证据。

## 效果标签与创意标签

当前周报效果统计依用户确认按优质→潜力→爆R→吸量互斥归类，一条素材只计一次；四类数量合计、有效总数与完整明细数核对。后台原始多标签另行保留。组队、700级等创意关键词可重叠，命中次数不等于去重有效数。

优质、潜力、爆R和吸量按当前面板定义读取。没有具体规则时只报告后台命中状态，不自行用“有消耗/有付费”生成潜力标签。临时关注的素材称“值得继续观察”，与正式潜力分类分开。

## 组合结果的含义

- 消耗与ROI1达到本次观察参数：只说明这两项达标；是否有效还要核对完整有效规则。
- 消耗可观察、ROI1较低、倍率较高：首日回本偏低，后续累计回本增长；达到何种目标另行判断。
- 消耗较高、付费成本较高：量级与付费成本有差异，原因需内容和对照证据。
- 低消耗、高ROI：付费结果集中于小样本，吸量和内容原因尚待验证。
- 老素材只有消耗：描述重新起量；付费结果未返回时保留未知。有付费仍需分别检查首日、后续和完整有效规则。
- 新角色未实装或版本刚变更：记录版本和成熟度，只作阶段性观察。
