# 最小任务：已有素材的一个事件粗剪

触发：用户要求先小任务验证或复用素材做后期。输入为当前项目、当前正式剧本、候选素材的版本/来源、事件因果及交付范围。验证样片沿用既有项目身份，放独立验证输出位置，不改写唯一当前交付工程。

1. 先读阶段0与6、完整执行顺序第10—11步和后期粗剪；随后只加载需要的工具说明。比对当前剧本与实际视频。旧文件可用于技术故障复现，但缺词、错词、动作或关键状态不符时标内容不通过，不能沿用历史采用标签。
2. 逐文件检查实际流。恒帧EDIT副本可能仅有画面；为每段显式记录画面文件、真正含声音的原片或独立音轨、原片入出点、时间偏移、速度及采用区间。不能凭同名、同长或成功转码推断音轨存在；合法静音镜头按项目标明。
3. 构建一个主序列的可编辑候选，采用画面在上，完整原片在下并留在素材箱；对应原声与备用静音轨分开。字幕与BGM需要时沿用当前正式声音规则。FFmpeg审核MP4与工程共享采用区间、速度和音轨，不宣称审核MP4是PR原生导出。
4. 保存后重新解析主序列数量、实际入出点、媒体路径、采用剪辑、音轨配对和备用静音。实际文件完整解码并检查事件动作及声音；机器转写、视觉采样、原生打开、听审、用户采用分计。解析通过只能说明文件结构，不证明PR原生打开或导出。

审查已有旧版预演或禁止新增费用时，按 [无付费预演与复验](nonpaid-previs.md) 记录当前正式版本、预演输入版本与实际检查范围。打包交付另读 [工程素材路径与搬移核对](portable-delivery.md)；媒体收齐、当前机器在线、异地重连与可独立搬运分别验证。

若内容不符，保留工程检查样片及具体问题；按原流程回到剧本、状态图或受影响生成片段，不用字幕掩盖错误声音、不为技术测试重生成整片。正式交付仍执行阶段7和完整验收；生成缺口遵守本次项目授权及额度，本任务通过不授权付费重生或发布。

入库前核对当前工作区实际附件上限；接口单次上传上限不代表工作区额度。超限时另建压缩预览并保留原审核片和当前工程，不将预览登记为原生导出或替换采用母版。新预览检查时长、流与解码，挂载后逐件字节回读；工程检查包明确记录外部原片依赖，不冒称可独立搬运。
