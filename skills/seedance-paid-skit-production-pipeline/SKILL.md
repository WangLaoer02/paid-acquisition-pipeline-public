# 买量短剧制作

把参考内容制作成可用的 A 段，或接上已有 B 段，交付成片和逐镜对应的分镜。默认最终总长10～25秒；明确时长和已采用稿优先。明确长参考改编成最终短剧时，默认只选一个有起因、转折、结果的小故事，A+B先为B段预留实测时长；单句或动作可作创意输入，最终短剧仍须形成完整故事。

仅要求拆解、创意或拟稿时，交付当次内容即止，不因此建项或进入生成。

## 从当前任务开始

输入是本次目标、参考原件或链接、已有项目标识及最新修改。在当前项目工作区执行：

```bash
python3 scripts/workflow_node.py context --item <真实item_id>
```

对象未知才先 `list`；A+B给context追加 `--route ab`。读取返回的目标、输入、动作、产出和下一步，只按当前节点加载正文；`--condition`只用于实际触发的分支。唯一项目Sheet决定状态和采用，节点位置不代表验收通过。

新参考在list中未匹配同一项目时，先运行：

```bash
python3 scripts/workflow_node.py context --node A01 --condition new-project --offline-preparation
```

核完原片后用同入口 `--node A02 --offline-preparation` 读取创意合同，再读 `--node A03 --offline-preparation` 的创意预演合同；A+B仍追加 `--route ab`。不借用旧item。建项按返回合同完成，再回到真实item。离线准备不能解锁付费生成或上传。

A01负责取得和核对原片、快速分段、结合本次买量目标选定范围、提取原片事实与待核内容，并单列吸引点、成立机制、迁移价值／边界三条简短参考判断（含暂定用途）；一句话或一个动作也可交接，分类不清不阻塞，分类细则与同版传递沿context的reference-scope.01。保留原件与初步分段，必要上下文与跨界对白动作局部核对；事实与推断／建议、未知分开，效果未验证；不在A01编具体新增角色对白、反转或完整剧本，也不单独触发第一次确认。A02承接同版选段及参考判断，提出保留与调整内容及简短改编方向，区分原片事实与新增前因、反转或结果；不重复选择故事或默认分析整片。A02按真实通用方法与适用专项主动提出多个实质不同候选，用户数量／框架优先；不先等采用，交A03为每个待选候选写关键画面文字和必要对白。A03将参考拆解、借用核心／适用方法、候选与预演一起首次确认；默认不生图或提前要求完整导演稿。正式剧本与分镜在后续阶段完善。仅要求原片拆解时停在A01。

## 制作与三次采用

| 阶段 | 要完成的制作内容 | 给用户看什么／下一步 |
|---|---|---|
| 参考与创意 | A01用 `seedance-douyin-video` 取得原片、按本次目标分段选范围、交两层简短正文：原片事实与参考判断；A02承接同版选段提出差异候选，A03做关键画面文字预演 | 在A03将拆解、方法、候选与预演一起首次确认，待核就地标注；采用后继续完整稿 |
| 完整稿与制作准备 | 读最新采用内容，备齐剧本／提示词、真实角色引用、B段及切点、模型／画幅／时长、当前报价和剩余预算、声音字幕／BGM、版本数及上传范围 | 一份可直接审阅的完整导演稿；在此一次确认同版稿与所需费用／动作范围，不先批稿再逐项追认 |
| 生成、剪辑与交付 | 按已确认输入和授权生成；等待时准备PR、B段、字幕音乐与上传。A由Premiere原生导出，接B默认FFmpeg；核对真实音画、总长和逐镜分镜 | 成片与对应分镜一起验收。采用且已授权上传后直接上传回读；未授权的动作停在具体准备结果 |

每个停点只有产物齐备且当前版未采用时才提问。已确认同版沿原范围继续，内部检查、建项、取片、写回与剪辑准备不逐项询问。用户改稿先重读并保留手改，只复验受影响镜头与下游。未知受理回查原任务，不重复提交。

## 当前阶段需要时再读

- 剧本、提示词与生成输入：读[Seedance适配](references/seedance-local.md)，再用当前节点指定的方法；偏心／双标／踩捧仅在A02／A07选择 `favoritism`，普通短剧不加载该专项。
- 物料需求、查库／补缺、写分镜、项目写回、剪辑、返工或最终交付：读[阶段操作](references/stage-actions.md)对应小节，细则仍由当前context返回。
- 已有独立成片只需上传：用已安装的 `rongyao-material-upload` 定位字段及 `rongyao-http-upload` 当前提交合同，无须虚构制作item。
- 首次安装、迁移或版本异常：读[部署与依赖](references/deployment.md)。日常任务不盘点全部Skill或读取整套审计资料。
- 工作台排队任务、用户要求记录或项目已选用工作台：才读 `seedance-prompts/references/studio.md`；普通制作不要求登记另一套状态。

日常每个停点只交一份直接可读内容；来源、原件和必要回执留原项目，不另附来源页、证据层级或工具流水账。未听审、未采用、未生成或未上传的部分如实区分。费用、上传和广告发布各自依原授权；实际生产继续使用通过当前发布校验的固定执行副本。
