# 最小任务：五秒动作参考与验收

触发：用户要求先做小任务验证。第一轮可选择现有真实动作片段，只验证来源提取与动作编排；用户要求AI成片时才进入本入口后续绑定和生成步骤，不把参考剪辑称为AI生成结果。

1. 读取当前项目及入口1、2、8节；固定面具或Kig按需读取kig-mode。核对真实原片、作品身份、原生尺寸、视频和音频流，选择能覆盖起势、运动及收势的约五秒区间，排除平台尾页。
2. 记录原片入出点、输出入出点、速度、来源音轨、角色/场景用途。原速提取不另加配音；ASR在音乐片段上的零星文字不能证明有对白，也不能证明没有人声。音乐曲名、版本和连续听审未核实就保持待验。
3. 交付实际片段、简短动作时间轴及检查结果。完整解码检查技术可读性；覆盖动作变化的连续帧用于视觉核对，采样检查不冒充全片逐帧或听审。被画幅裁掉的脚和接触点保持不可见，不以此证明全身支撑通过。
4. 动作平淡先调整已核实区间、动作次序、停顿和景别；不靠改固定面具眼口、整幅缩放或重复静帧冒充表演。裁剪后声音与运动从同一原片区间对应。

参考提取完成不代表角色母版认可、音乐版本确认、真实绑定、AI动作生成或用户采用。继续AI生成时按原3—7节补齐各项输入与权限；已有成片验收仍完整执行第8节，不继承该参考的通过状态。

入库前核对当前工作区实际附件上限；接口的单次上传上限不等于工作区额度。需压缩时另建明确标注的预览，不覆盖原片，不改变入出点、速度或音轨。新预览重新检查时长、流和解码，写入后逐件字节回读。

## 已有生成的无付费复验

适用：仅审查、禁止新增费用，或先用已有成片验证修复。保留原八步和后续生成能力，本分支不提交新的图片或视频任务。

1. 读取当前项目、声音模式和最新修订；存在 `currentRevisionRef` 时读取其 `stateFile`，顶层历史提交不代替当前输入。用同一 operation 只读查询终态、取回实际文件；记录原任务、真实文件及 SHA256，不把本次下载记成新生成。
2. 用真实 PTS 取帧，保留帧号与源秒数；覆盖准备、主体动作、接触、落脚及收势，加密检查候选切点和叠化。将计划和实测并列：动作开始与结束、局部展示占时、固定部件首次完整可见时点、视差与接触点。局部合格、运动通过和按计划执行分别判定；未出现的动作不由提示词补证。
3. 硬切检测、运动量和能量峰只定位候选区间。阈值未检出不能写“无切镜”；看到叠化就登记过渡区间。构图位移不证明短弧或侧移视差；音乐瞬态不证明乐拍、段落重音或踩点。
4. 现有动作可用而陈列过长时，按本次允许范围精剪：逐段记录源 In/Out、帧率、帧数、输出 In/Out、速度、切镜和声音映射。保留原片，另存审核候选；新增断切标为剪辑改编，不伪称原来连续。整体缩放、变速、重复静帧不能修复真实动作缺失。关键结构或运动无法免费修复时保留失败，不触发补生成。
5. 按项目声音模式完成实际合成。需移除模型音轨时显式选择原声音源并核对输出流；记录来源、实际曲段、正常速度、编码及容器/视频/音频各自时长。压缩编码导致字节不同，用解码内容对应检查；重编码输出不宣称源字节相同。音视频尾差写实测值和呈现影响，不把编码补齐当新增曲段。来源对应、完整解码、版本听审、对白/无对白和踩点分别记录，不能核听保持待验。
6. 制作方提供原片、候选、源时间映射与实际检查；审核方独立看实际帧，结果写回唯一项目检查点。实际文件、节奏改善、技术可读、声音待验、用户采用及发布分计。采样不足以认证全片逐帧、面具稳定或解剖结构；保留样本范围和不可见部位。必要附件沿原素材库归档，不另建项目主控。

归档优先保留可读本地文件、来源和SHA256，现有项目记录只保存对应稳定文件位置与检查结果。恢复时先核对本地实件及原任务标识；需要取回远端原件时走该来源已经授权的工具，下载后核对字节与类型。无取回能力只阻塞该附件，不要求知识库账号，也不把文本响应当视频文件。

仅支持 UTF-8 文本下载的接口不能验证视频；原生挂载、大小匹配和文本附件通过分别记录，实际视频下载后才能核对字节。浏览器显示无权访问时记录当前账号与原项目的访问状态，保持浏览器访问项待验；已授权连接器的实际字节回读独立判定。保留原文件、上传ID与页面，不新建副本、不改权限，也不把可用连接器等同于浏览器账号可访问。
