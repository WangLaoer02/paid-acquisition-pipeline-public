# Kig系列声音与表演分支

仅在当前项目明确属于Kig系列时读取。此分支保留原系列要求，不限定博主、角色或服装；角色具体几何与材质以自己的母版为准。

- 不设置人物对白、旁白或角色配音。BGM使用真实抖音作品的同版音乐，不新生成、不用AI重制；原歌曲自身人声可保留。
- 先选原曲片段，保存作品链接、曲名或音乐ID（可取得时）、曲段起止和主要拍点，再安排姿态变化、舞蹈重拍、切镜与特写。未取得选定真实原曲时保持制作准备。
- 提示词写“无对白、无旁白、不生成BGM”。成片剪辑移除生成声轨，换入选定真实音乐并对齐拍点，保持原曲版本和速度。相似的模型歌曲不代替原曲；不能核听时保留待验。
- 佩戴式刚性头壳的眼片、眼口几何、表情和材质按母版固定；情绪由整个头壳朝向、肩背、腰胯、手势、抬腿和停顿表达。固定头壳不要求身体或衣料静止，耳部是否随壳整体移动按角色真实结构判断。
- 舞蹈可从已有猫俏俏库、真实抖音舞蹈、女韩团官方舞蹈、练习室或直拍选取实际片段与时间码；这些是已有可选来源，不是所有项目必须绑定的账号。尚未收录的来源先核验入库，不标已绑定。
- 展示姿态可选择猫摆手、侧坐、半蹲、侧身站立、靠近递物等，以本篇内容和角色结构决定。动作参考负责身体编排，机位可重新设计，不能把新增连接动作称为原片已经拍到。
- 机位可选全身、侧面、低机位、手套/腰结/织物微距及头肩近景；拍清支撑、抬腿与落脚，保护角色角、耳等轮廓。微距和固定表情不能替代主题动作，避免整片重复站姿。
