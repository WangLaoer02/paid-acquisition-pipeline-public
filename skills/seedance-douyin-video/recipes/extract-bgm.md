# 抖音视频 BGM 元数据提取

仅在用户明确要求识别BGM或音乐信息参与当前分析时使用：

```bash
python3 ~/.codex/skills/seedance-douyin-video/scripts/extract_bgm.py "<抖音分享链接或分享文本>"
```

使用维护中的脚本，不复制历史实现。它读取抖音作品的音乐元数据，不下载音频；返回歌名、作者、音乐ID等实际可得字段，缺失项保持未知。

元数据缺失不等于原片无音乐。需要定位原片声音时，用 `scripts/local_audio_probe.py` 生成本地切片；能量峰值不等于已确认的音效，不能据此宣称听辨通过。

元数据不是音乐使用授权。外部识曲服务仅在已有可用工具及当前授权范围内尝试，不自动安装、消费、改网络或接管其他剪辑工作流。

公开解析缺少元数据时默认返回待核，不自动启动独立浏览器。只有当前任务明确允许独立浏览器时追加 `--allow-browser`；用户指定现有登录会话时继续沿已授权页面读取。PGC字段只是平台标记，不是商用许可。
