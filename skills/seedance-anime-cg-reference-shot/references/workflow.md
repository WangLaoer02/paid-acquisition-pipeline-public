# 二次元CG短片工作流

## 素材与范围
先查看原三视图、背景和成片参考。三视图锁定人物身份、画风与材质；背景锁地貌和光源；分镜只负责动作空间和景别。保持原素材，不用派生失败图继续叠代。
CG感通过构图、纵深、主次光、环境互动和动作节奏实现，不把二次元人脸改成写实3D。原IP设定用于参考研究，当前制作采用本项目已准入角色；原案例的原创角色条件不推广为其他任务的角色事实。拒审素材按原平台结果保留记录，不自动重试。

## 制作顺序
1. **参考与时间线。** 从实际看过的成片提取一个完整因果单元：危险或目标→应对→可见结果。保留来源和实际观察范围，不凭标题编造动作。5秒只放一个清晰事件。
2. **简化故事板。** 先画一张无身份体块人的动作板，保留肩胯重心、位移、来向、接触和终态。场景用近景、水体、远景体块及必要中文说明；不固定脸、服装纹理或过多中间姿势。按事件决定格数，格数不等于镜头数。
3. **图文一致。** 图管空间与动作关系，文字补速度、发力、镜头和特效时序。先核对持械手、道具数量、方向和结果；发生冲突先修图或文字，不靠“以文字为准”覆盖。分镜不能被当作成片美术或多格首帧。
4. **镜头与节奏。** 景别变化必须带来新信息。跟随危险、发力或落点，利用前景遮挡与视差，避免固定站位和每镜结束等待。接触段包括接近、瞬间碰撞和分离，不能整段停在碰撞姿势。少切镜、简单运镜。
5. **分层特效。** 安排持续环境、动作触发、接触峰值、结果余波四类效果；按场景选取，亮度与密度有主次。具体做法见特效规则。特效必须跟随动作，不能遮掩错误。
6. **五模块提示词。** 固定顺序：全局视觉风格锁定→角色锁定→场景锁定→分段剧情→全局限制。时间段内写初始状态、连续动作、镜头跟随、可见结果。原图已有的信息不反复堆写，只补易漂移要点；不堆“顶级画质”等空泛词。具体模板读[本地Seedance格式](../../seedance-prompts/references/formats.md)的五模块；旧原文示例不决定新任务参数。
7. **三图绑定与生成。** 上传前读取每张参考图的真实尺寸与宽高比，依据当前平台要求适配；本案例使用16:9独立补边副本，保留原文件，禁止拉伸人物或裁掉分镜。补边后核验内容不变。按当前输入清单编号，原案例为1三视图、2背景、3分镜；缺图或模式不适用时按职责调整，不为凑三图新增资产。正文引用须与真实输入对应。CLI使用公开节点占位符，回读最终引用顺序与正文槽位，手写@图片编号不算绑定。执行读取当前dreamina-canvas-cli Skill、认证、schema、模型和报价；参数、当前报价与授权按[Seedance共用合同](../../seedance-prompts/references/contract.md)核对，历史100积分不是通用预算。任务未终态时沿原身份查询，避免重复提交。
8. **看结果再复用。** 核对实际时长分辨率和解码，再检查人物、动作因果、景别、特效触发与衰减。注明抽帧还是实时观看。技术成功、视觉效果、用户接受分别记录；修改已发现的问题，不以追加特效掩盖动作缺陷。

## 保存与维护
保留原素材、故事板、可读提示词、实际提交提示词、成片、来源和简短效果记录。必要的任务身份、素材哈希和授权状态留在任务索引或审计记录，工作流正文不堆执行日志。
当前工作流只有一个入口。过期入口、一次性脚本和冗余响应退出活动目录；有复现价值的旧提示词、案例及日志可恢复归档。新方法经用户选择后并入规则，不把已知缺陷写成成功经验。
