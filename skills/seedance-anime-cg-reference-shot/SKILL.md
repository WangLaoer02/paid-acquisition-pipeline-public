# Seedance 二次元CG参考镜头

执行读取 [工作流](references/workflow.md)。这是唯一当前流程，包含素材职责、时间线、简化分镜、五模块提示词、三图真实引用和视频验收。

设计氛围与打击反馈时读取 [特效规则](references/effects.md)；整理提示词时读取[本地Seedance五模块](../seedance-prompts/references/formats.md)。[原模板迁移说明](references/user-video-prompt-template.txt)只用于追溯格式。五模块顺序保留，原图信息不重复堆写。

需要了解依据或避开已知失败时读取 [来源与效果记录](references/sources-and-lessons.md)。[特效案例提示词](references/atmosphere-example.txt)保留实测原文，不视为无缺陷标准答案。

新任务与现有任务的参数分别按[Seedance共用合同](../seedance-prompts/references/contract.md)处理。原案例5秒、100积分及固定输入组合仅在当前项目仍明确采用时适用，不是新任务费用授权。任务标识、素材哈希和实际引用留在项目记录。

## 可选工作台

只有用户要求记录、从工作台排队任务续接，或当前项目已选用工作台时，才读取 `seedance-prompts` 的 `references/studio.md`，沿同一 task/run 保存进度与候选。普通创作、采集与字幕直接在当前任务交付；工作台未配置不阻塞这些工作，也不替代原项目状态。
