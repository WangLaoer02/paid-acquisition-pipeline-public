# 战斗分支与常见修复

仅选当前任务适用的分支。以下是创作提示词的编排建议，不是动作捕捉或物理模拟保证。

## 全流程怎么组织

| 阶段 | 应让观众读到什么 | 可以怎样写 |
|---|---|---|
| 初始目标与空间 | 谁想推进什么、双方相距多远、障碍在哪 | 守住出口、争夺物件、逼退对手；固定双方朝向与活动范围 |
| 触发与接近 | 为什么此刻进入交锋 | 一方抢位、试探、切断路线；另一方被迫防守或主动应对 |
| 攻防交互 | 来招、应对、接触或落空各是什么 | 一次主要攻击与一次对应防御，结果改变站位或控制权 |
| 变化与代价 | 为什么不能照原样继续 | 改变节奏、露出空档、失去武器、地形受损、护盾减弱 |
| 转折与兑现 | 哪个机会改变局面、如何看得见 | 利用之前形成的角度或资源变化；结果与前面铺垫相关 |
| 收尾与余势 | 目标达成、失败还是仍未分胜负 | 动作减速、落地与站稳、通路变化、双方重新对峙 |

微型交锋可把触发和接近合在开头，把转折和兑现合成一次交互。开放结尾须看得见当前局势，不默认写出胜者。用户只改中间一拳时，只补这一拍所需的前后状态。

## 按战斗类型补信息

### 徒手与近身

优先写清距离、支撑、动作路径与对手反应。力量由身体带动、接触和失衡共同表现。贴身后长距离挥击、脱离距离的接触会冲突，改成符合当前空间的动作或先交代拉开距离。

摔投／擒抱重在接触关系、共同重心变化、失衡、落地和松脱／控制的连续状态。只写影视可读的动作，不补现实制伤步骤。地面接触不能略成“突然倒地”。

### 兵器与盾牌

写明谁持有什么、活动空间与兵器长度关系。交锋用碰撞、滑开、被架住、撤回或脱手表现变化；火花取决于接触材质和风格。兵器越过对手后必须有收势或改线才进入下一招。断裂、弹开、掉落延续到后续镜头。

### 远程攻击

表现“发现或瞄准→发射→传播→遮挡／防御／命中→结果”。时间紧时压缩瞄准，保留路径和结果关系。速度太快的弹体以发射、短轨迹与着点衔接，不强行让普通人物在弹体贴身后从容闪避；超常反应需要已有设定。掩体损坏影响之后遮蔽能力。弹药、装填、能量等只在原设定相关时追踪。

### 异能、法术、机甲与巨物

先给清楚的交互规则：由谁／何物发动，作用范围与目标，可被什么阻挡，有何代价。把抽象技能写成起始形态、路径、碰撞／作用及残留；“光效更强”不能替代局势变化。护盾受损之后的保护程度、召回物的归属、能量耗尽后的动作要一致。飞行、瞬移、变形有明确前后位置与状态，服从既定规则，不强行用普通人体物理否定题材。

### 多人战斗

给每人稳定称呼及位置。围绕主要交互组织镜头，其他人可以推进、绕行、受阻、保护目标或准备支援；同时写清这些人为何暂未介入。避免一镜列出所有人同时完成复杂连招。切换焦点时交代新威胁来自哪里，防止角色互换与空间重置。

### 空中、水下与特殊地形

写明推进力、支撑／抓点、惯性与落点。地形参与战局后保留变化：破洞影响通路，湿滑影响支撑，水下动作受到题材规定的阻力。架空战斗可夸张，但同一段遵守同一套规则。

## 从症状定位缺口

| 原稿症状 | 先查什么 | 优先修复 |
|---|---|---|
| 像慢速练招、没有攻击意图 | 距离与目标是否成立、速度是否全程均匀 | 补有效接近、明确目标与速度变化；保留用户要的慢招 |
| 手脚乱挥、对手互不相关 | 来招与应对是否一一对应 | 改成可读的一次攻防，写明变线或失衡原因 |
| 拳脚穿过身体、接触虚 | 接触点、路径、遮挡与反应是否矛盾 | 简化重叠，选能看到关键交互的机位；先接触再反应 |
| 很炫但不知道发生什么 | 特效和镜头是否遮住主交互 | 缩小特效范围，保留轮廓和着点，补结果状态 |
| 每招都把人打飞 | 是否所有反馈被写成同一级别 | 建立轻重差与重量感，保留一次主要重击 |
| 两秒塞了十种招式 | 时长与动作可读性是否冲突 | 留主要交互，删装饰招式，必要时分镜但不私自延时 |
| 切镜后站位或武器突变 | 上一镜尾态与下一镜首态 | 用换位、拾取、交接或建立镜头补过渡；已有设定才可召回 |
| 加了很多技巧但不像原稿 | 是否改变人物、能力、胜负或风格 | 回到原意，只修本次要求的动作表达 |

## 文字稿到视频的验收

有成片后再检查关键接触前后、完整位移、反应时机、落点和下一镜连续性；不能只凭首中尾三帧确认快速动作成功。反馈修改时定位到具体时段和缺口，只改相关动作条件，再核验改动后的整条交互。
