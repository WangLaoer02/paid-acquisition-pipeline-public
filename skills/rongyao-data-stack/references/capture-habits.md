# 抓数习惯与日期来源

此文件定义可覆盖的工作默认值，不把历史示例或默认值伪装成用户已确认事实。参数优先级：本次明确要求 > 本机显式配置 > 已披露兼容默认值。只有无法安全确定项目、完整历史范围、特殊指标口径或登录动作时才问用户；不要要求用户提供已能解析的周一日期、gid或输出路径。

## 日期与项目

- 火影对应忍界大战 gid=193；返回值须核验。别名不是当前账号可见全部项目的证明。
- 本周：Asia/Shanghai 周一至今天；跨月、跨年照自然周计算。本周只过了几天就只查这几天，不补成上周或未来日期。
- 上周：上一自然周周一至周日。最近一周：滚动7天，默认结束日今天减2天。近期：滚动31天，默认结束日今天减2天。
- 明确起止日期优先。未要求留2天时不缩短“本周”；输出保留最近两天可能未成熟的提示。留2天只是一种保守观察口径，不是后台已完成归因的证明。
- 若本周刚开始而用户要求留2天，可能没有可查日期；报告这一事实，不悄悄查上一周。
- 不自动追加上一期。只有变化/趋势/对比请求才使用紧邻的等长上一期；部分周对比不是整周同比。

## 素材产出范围不是投放范围

`material_performance.py run` 的选择顺序：

1. `--material-range` 指定完整起止；
2. `--material-start` 指定起点，终点运行当天；
3. 本机环境配置 `RONGYAO_MATERIAL_START` 指定起点，终点运行当天；
4. 保留旧脚本2023-01-01至运行当天的兼容范围，输出 `material_range_source=legacy_default_unverified`。

第4项不是已核验的项目上线起点，也不是用户长期习惯。普通本周表现请求可披露此窗口后继续；用户要求全部历史、上线以来或早于2023的素材时，不可用该窗口冒充全量，需要可核验起点。明确范围也不自动证明历史覆盖完整。

规划器会把实际范围打印出来并显式传给底层抓取。`readonly_capture.py`、月消耗、产出数量和素材编号入口仍要求完整 `--material-range`；可复用已解析且适用于本次请求的范围，但不能静默套用与该任务无关的窗口。

默认在同份投放CSV中按产出日期拆出目标周期新素材；不再为这次拆分查询第二遍。素材日期筛选会限制样本，不只是展示标记。若筛选窗口没覆盖完整新产周期，标记 `new_material_window_covered=false`，不得说新产全量。

## 登录、负载和文件

- 普通已授权抓数直接用既有助手查询；成功数据回包和身份核验验证本次访问。不要为了确认登录额外先查一次总计。
- 会话缺失、浏览器进程已退出、浏览器存活、登录页存在、已认证访问是不同状态。`state_missing` 或 `process_missing` 在查询前用固定专用配置自动启动；只有服务端已跳转登录页时才请用户手动登录一次，不索取凭据。
- 已知专用 Chrome 进程存活但 DevTools 断连/状态不明：停止，不启动第二个会话、不转读磁盘 Cookie。磁盘 Cookie 仅是显式兼容入口。
- 无结果就保留未知，查询提交后不自动重试或重放。一次请求中的新老素材/方向分析在本地完成。
- 相同项目、投放日期、素材日期和数据维度优先命中短期精确缓存；不得用近似窗口替代。对实时性有明确要求时强制刷新。
- 两个互不依赖的普通对比区间可最多2路并行；素材编号等高成本查询保持单路。并行不改变每个区间只提交一次、失败不重放的约束。
- 输出目录自动生成且唯一，显式目录必须为空；失败时保留已写出的文件用于核查，不覆盖之前结果。
- 复用CSV前核验项目、双日期边界、来源时间和字段，不能用旧档案冒充实时。

## 指标和方向

观察消耗500元、ROI1 9%、2日倍率1.9仅是当前分析参数，不是已确认业务标准。优先用户或后台明确给出的标准；阈值来源随结果保留。

后台“优质”等标签、聚合指标达标、具体视频结构有效是三个不同判断。至少结合方向聚合、可观察样本数量、多条达标复现、新老素材贡献；单条头部不推广到整个方向。未看视频只能判断指标、标签或名称，不能推出内容因果。

普通本周问题输出简洁方向结论；没有真实返回结果就不做真实方向判断。不自动生成周报、上传飞书或追加历史抓取。
