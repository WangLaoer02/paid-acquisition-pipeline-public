# Seedance 特效提示词写作

把“想要什么特效”写成模型能表现、制作者能验收的画面变化。支持从零写、局部润色、按参考拆解和根据失败结果修订；手绘感是风格分支，不能强加给其他特效。

视频部分按[Seedance共用合同](../seedance-prompts/references/contract.md)处理格式、参考与参数；已读同版时复用。只处理本专项需要的内容。

## 执行

1. **锁定意图。** 从当前请求提取主体、原动作、特效用途、风格、输入方式、镜头和已定参数。润色时保留人设、剧情结果、参考绑定、画幅、时长与用户手改，只改影响特效表达的部分。用户只要短句就交短句；只有缺口会改变核心效果时才提问，其余用少量合理补充完成。
2. **写清变化。** 内部依次确定：起始状态 → 什么触发 → 从哪里产生 → 如何发展或接触 → 峰值/结果 → 如何消退及最终留下什么。静态图片只选一个关键状态；持续光环、天气等允许维持或循环，不强加爆发。循环要求首尾形态、运动方向和强度衔接。
3. **把形容词落到画面。** 确定主要轮廓、介质、尺度、配色、明暗层次，以及运动的方向、速度变化、路径、密度、拖尾和节奏。先明确一个主效果，辅助效果只服务于它。“震撼”“高级”“魔法感”需要转为可观察描述；不靠叠加形容词或塞满特效增强力度。针对手绘等风格或具体类型，按需读取[类型写法](references/effect-patterns.md)。
4. **连接空间与动作。** 明确特效锚定的手、脚、武器、物体、地面或空间；区分附着、脱离、跟随和撞击后的状态。说明必要的前后遮挡、接触点与环境响应，使动作、特效运动及结果一致。只加入画面需要的光照、阴影、反射、风、扬尘等响应；平面贴纸、线稿和抽象图形可采用图形交互，毋须强加写实物理。
5. **匹配输入和镜头。** 纯文字要补足可见主体与场景；图生视频沿用图中外观、构图和起点，重点写变化；视频编辑说明哪一层可改、原动作与哪些区域需保持。纯特效素材需写背景、边界、出画规则及合成用途；只有目标工具支持时才设置真实透明通道，不能把黑底视频叫作透明视频。需要多阶段制作时读取[制作与迭代](references/workflow.md)。
6. **压缩交付。** 用自然连贯的中文给出可复制正文，按发生顺序写，必要时分镜或标相对节拍；时长已定才分配秒数。合并重复词，消除“固定机位同时绕拍”“爆炸后仍完整悬浮”等冲突。镜头变化服务于效果可读性，避免同时写多个竞争运镜。仅在有实际误生成风险时补短约束；平台有独立负向栏才分开填写。只需润色时，默认一版正文加至多两句关键改动，不展示内部检查表。

## 可调骨架

> 【画面及必须保持的主体】。当【动作/条件】发生时，【位置】出现【主要特效的轮廓、介质、颜色与尺度】，先【形成】，随后沿【方向/路径】以【速度与节奏】发展；与【对象】接触时【形变/遮挡/环境响应】，达到【可见峰值与结果】，最后【消退方式与结束状态】。【服务于效果展示的镜头及必要保持条件】。

这只是检查缺项的骨架，不要求每次填满或按固定字数输出。静帧、持续效果、局部改词分别删去无关部分。原稿中未要求的角色、动作、剧情、字幕、声音及镜头不为填模板而新增。

## 验收与修订

交稿前检查：谁/哪里发生、为何此刻发生、如何运动、与谁交互、最后变成什么，是否能从正文读出；再按本任务挑选关键判据。静态不验动态，装饰层不验冲击破坏，循环不验强制消散。

有生成结果时，比较起点、触发、峰值、结束与关键接触帧；视频还需检查中间帧的附着漂移、穿模、主体变形和无故闪烁。没有看过结果时只称“提示词已检查”，不声称特效已生成或效果已验证。失败修订先定位实际偏差，优先改最相关的变量，保留已成功的部分。

## 边界与衔接

- 本Skill负责提示词及必要的制作说明；生成、积分消费、软件工程、上传和发布沿各自任务授权执行。
- 尊重当前任务的模型和规格；不从来源视频推断未展示的完整提示词、种子、工具参数或成功率，也不为润色自动切换模型或增加生成次数。
- 当前会话的最终视频时长与生成片段规格分别处理；特效段分配在既定总时长内，不能因特效阶段较多自动拉长成片。
- 与既有视频提示词规范一起使用时，本Skill只补充特效变化及交互，沿用既有输出格式，不接管剧情和整片流程。
- 只有追溯本Skill与参考视频的关系时读取[来源与适用范围](references/source-note.md)。

## 可选工作台

只有用户要求记录、从工作台排队任务续接，或当前项目已选用工作台时，才读取 `seedance-prompts` 的 `references/studio.md`，沿同一 task/run 保存进度与候选。普通创作、采集与字幕直接在当前任务交付；工作台未配置不阻塞这些工作，也不替代原项目状态。
