# 特效提示词的制作与迭代

用户要求完整方案、给出失败结果，或需要多阶段交接时读取。日常一句话润色不用输出本流程。

| 环节 | 需要决定什么 | 交接内容 |
|---|---|---|
| 需求/参考 | 效果服务的动作或信息、必须保持的元素、可变范围 | 一句效果目标；参考中的可观察特征与未知项分开 |
| 视觉设计 | 轮廓、介质、颜色、尺度、层次及重点 | 峰值画面描述；必要时给起点/峰值/终点关键帧描述 |
| 动态设计 | 触发、形成、发展、接触、消退或循环 | 因果顺序、相对节拍或既定时长内时间段 |
| 生成路线 | 纯文字、参考图、现有视频编辑、独立特效素材 | 与当前工具能力匹配的输入及提示词；模型未定时保持中性 |
| 合成与剪辑 | 背景类型、遮罩、前后层、追踪锚点、色彩和边缘 | 用户需要独立素材时才交付合成说明；保持与提示词正文分开 |
| 结果检查 | 原意是否兑现、主体是否稳定、空间和时间是否连贯 | 实际偏差、对应画面/时间点及修订目标 |
| 修订/交付 | 哪个变量导致偏差、已成功部分如何保持 | 一版修订正文，必要时说明改动；真实生成和验收另记状态 |

路线由目标和现有输入决定，不强制先做图、先生成测试片或先拆层。完整流程指需要时能覆盖各环节，不代表每个请求都执行所有制作步骤。

## 输入适配

- **文字生成**：主体/场景只补到理解效果所需；说明是完整镜头还是独立特效。描述可见结果，不写工具不支持的内部参数。
- **图生视频**：绑定真实图片编号与用途，沿用图中已定结构。起始图已经有火焰时，写“现有火焰继续…”；若要求从零出现，需要先解决起始状态冲突。
- **视频编辑**：指定原素材中的动作时刻与可改区域；只追加效果时保持原始主体、动作、背景、时序和镜头。若不支持精确区域编辑，交代限制并给可执行替代方案，不伪称提示词可锁住每一像素。
- **独立特效素材**：说明二维/三维视角、画幅内安全边界、空镜头部/尾部是否需要、是否允许出画、是否循环。透明需能力支持；黑底适用于某些发光类叠加，但不能直接保留黑色烟尘，也不等于alpha通道。需要精细合成时将遮罩、光效与实体烟尘按用途分别设计，避免一概屏幕混合。
- **静帧**：选一个明确状态，写形态、位置、光照、遮挡及结果线索；不用同时要求一张图展示互相冲突的起止形态。只有用户要求时才生成过程图或分格。

## 节奏与参数

先保证关键变化在所给时长内能读清，再给次要残留分配余量。持续效果采用建立—维持—结束/循环；瞬发效果采用预备—触发—峰值—余波；变形采用起态—传播—终态。根据具体目标取舍，不硬套同一个节奏模板。

模型、分辨率、单次生成时长和最终成片总时长是不同参数。沿用当前任务已确认的值和用户默认；润色不代表提交生成或追加费用。提示词没有能力替代模型目录核验与实际成片时长检查。

## 按结果修订

| 实际偏差 | 先查什么 | 主要修订方向 |
|---|---|---|
| 效果跟丢手/武器 | 锚点、附着/脱离时机是否含糊 | 写清跟随对象，何时释放，释放后沿什么轨迹 |
| 只有光团，形状不可读 | 轮廓是否被强烈光芒淹没 | 明确核心外形，降低泛光遮蔽，保留边界 |
| 接触不成立/穿模 | 接触点、深度关系、前后顺序 | 给明确遮挡和撞击前后状态，简化冲突动作 |
| 变形像直接换图 | 中间传播过程是否缺失 | 写材料/轮廓从哪里向哪里转换及终态稳定 |
| 全身和背景一起抖 | 风格变化范围是否过宽 | 把逐帧线条变化限定在特效层，稳定主体与镜头 |
| 结尾突然消失/循环跳变 | 消退或首尾衔接是否缺失 | 指定残留如何减弱，或让末态速度和形态衔接首态 |
| 主效果被碎屑抢走 | 元素数量、密度及峰值是否竞争 | 减少辅助效果，明确视觉主次与节拍错开 |

每次根据已观察结果选择最相关的少数项。无结果时提出待验证假设，不能把失败诊断写成确定原因。
