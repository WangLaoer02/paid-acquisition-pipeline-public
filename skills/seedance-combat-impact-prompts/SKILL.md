# Seedance 战斗冲击提示词

把“更燃、更炸、更有力量”改写成可以看见、前后连贯的动作与反馈。冲击帧只是可选表现手段；用动作、时间、构图、受力和环境共同建立冲击。

视频部分按[Seedance共用合同](../seedance-prompts/references/contract.md)处理格式、参考与参数；已读同版时复用。只处理本专项需要的内容。

## 调用方式

用户要求战斗提示词润色、打击感增强、冲击帧直出，或正在优化的战斗段明确存在这些问题时调用。可作为其他提示词写作流程中的局部增强模块，沿用上游文本格式与素材标识。普通对白、日常动作和非战斗特效按原需求处理；用户只要一条增强句时只交一条。

## 写作流程

1. **锁定原意。** 从原稿确认人物、武器／技能、空间、攻防关系、结局、风格、镜头约束与已有时长。保留台词、参考图编号、角色外形及手工指定项。缺少的非关键细节使用最小假设；胜负、命中与否等会改变剧情的信息缺失时，沿用开放结果或先询问。
2. **找到冲击事件。** 判断这一拍是接近／蓄力、出手、命中、格挡、擦过／落空、碰撞、爆发还是余波；写清力从哪里来、向哪里走、作用于谁或什么、造成何种允许的结果。连击选关键重拍形成轻重变化，终结技才使用该段的最高强度。
3. **补足因果链。** 优先修复动作和反馈，再选表现手段：准备状态 → 加速轨迹 → 接触或最近掠过时刻 → 与事件相符的反应 → 余势／恢复。并非每一拍都要写五段；短句也应让关键事件和结果可读。
4. **选择最少的有效增强。** 从下表选择适合当前问题的手段；已有动作清楚时仅增加必要的节奏或冲击表现。保持一个主要视觉焦点，让最强变化落在同一事件上，避免把全部手段逐项堆入每次攻击。
5. **写回原稿并自检。** 将效果直接绑定到具体动作时刻和空间位置。回读攻防、方向、结果、主体可见性及镜头连续性；删除冲突、重复和模型无法确定执行的空泛形容。只有写作完成时说明提示词已完成，视频效果须由实际生成另验。

## 冲击增强的选择依据

| 层面 | 写进提示词的可观察变化 | 选择与约束 |
|---|---|---|
| 身体发力 | 支撑脚蹬地、重心转移、髋肩带动、武器惯性与回收 | 跟随原动作与身体结构；力量感先有来源，再有爆点 |
| 速度与节拍 | 起势略收、突然加速、接触瞬间短促顿挫、随即释放余势 | 保留快慢与轻重对比；慢动作或停顿服从既有时长，不拖住整段连击 |
| 接触与受力 | 接触点清晰；局部压缩、姿态失衡、后滑、兵器弹开、护盾凹陷等 | 只选原设允许的反应；格挡、落空、无伤、破防分别写，力量方向与反馈方向一致 |
| 冲击画面 | 一瞬的高反差剪影、黑白明暗反转、色块爆闪、放射线或局部轮廓强化 | 绑定最关键接触或爆发；随即回到同一动作与位置；写实、禁闪或保持色彩时改用实体反馈 |
| 镜头与构图 | 沿攻击方向跟进、接触处短促震动、轻微回弹、前景掠过、碰撞后拉开显露结果 | 摄影机服务事件；固定机位和一镜到底分别保留，震动不能代替受力或遮住接触 |
| 材质与环境 | 火星沿刃缘迸射、尘土受压外推、碎片顺冲量飞出、水面／衣物／植被响应 | 材质、传播起点和方向对应；破坏尺度服从场景及原设，不凭空升级爆炸 |
| 声音与恢复 | 挥击破风、接触脆响／闷响／金属颤响、低频冲量、碎片尾声；恢复中保留惯性 | 仅在所用流程支持音频或用户要声音时写；峰值对准事件，声音类型对应材质，尾声交代结果 |

需要跨题材写法或故障修正时，按需读[场景适配与例句](references/patterns.md)。仅当追溯本Skill来源或补录原教程时，读[来源状态](references/source-status.md)。

## 冲击帧直出的具体写法

把它当作生成视频内部的短暂画面变化，嵌在动作之中：

> 在【明确接触／爆发时刻】，画面一瞬转为【与画风相容的一种高反差表现】，保留【双方轮廓、接触点和攻击方向】，随后立刻回到【原色彩／原场景与同一动作】，显露【符合原剧情的受力结果】。

这只是句法，不是每次必填模板。用户只说“加强冲击”时，先判断风格是否适合插入冲击帧；不默认把写实片改成黑白漫画。用户明确要黑白冲击帧时落实短暂反差、事件同步和回归连续性。帧数／毫秒只在已有帧率与时长预算、且目标工具支持时作为目标参数，不承诺逐帧精确控制。静态图请求只描述单幅接触瞬间，不套用时间恢复链。

## 边界与交付

- 默认交付可直接粘贴的润色后提示词。用户要解释时，再简短说明改了哪些事件与反馈；原稿不足时给最小可用补充，不自动扩成完整剧本或全新战斗。
- 保留模型、画幅、时长、已有分镜和@图／@视频绑定；只润色时不擅自更换生成参数、添加镜头或延长成片。用户明确要求重写或改招式时以本次要求为准。
- 多角色分别写攻击者、承受者和位置，连续镜头衔接前后姿态。落空采用擦过的气流、轨迹或被击中环境的反馈；防守成功保留防守状态；无破坏要求保留场景完整。
- 强度来自对比和清晰结果；全程闪白、持续强震、满屏烟尘容易掩盖动作。降低强度时优先保住动作链与接触可读性，只减装饰。
- 本Skill负责写作与文本检查。调用不授权生成、消费积分、上传或发布；“提示词直出”是写作目标，不能作为所有模型必然实现该效果的保证。
