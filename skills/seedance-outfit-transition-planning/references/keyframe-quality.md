# 关键帧设计与质量流程

在已确认图件缺口、需要制作/修订或诊断图片效果时读取。角色与参考职责沿主Skill，视频输入模式先按[视频制作](video-production.md)选择；本文件不要求新增图，也不扩大生成或费用范围。

## 先区分四类图件

| 图件 | 职责 | 完成依据 |
|---|---|---|
| 身份/造型参考 | 已有三视图、原母版决定身份和对应套装，不随派生顺序改变 | 已查看对应版本，注明共用身份与前后各套造型职责 |
| 布局/动作预演 | 粗略人物轮廓、姿态、景深层次与接触关系 | 能判断构图、视线、运动方向和切点；不必制作高清成图 |
| 最终关键帧 | 某个具体可拍摄时刻的画面 | 角色、画面表现、动作状态与邻帧连续性均完成目视检查 |
| 视频实际输入 | 从上述素材中选择当前模式需要的文件 | 上传/绑定后回读角色、顺序、版本及模式 |

三视图是可复用的来源；是否整板、使用其中已有视角或仅供图片制作，取决于已选视频模式及该图职责。三视合板提供同一人的多个角度，不表示多个人物；需要单幅开场时应使用具体画面，不将角色图板误作首帧。分镜总览供审阅，选中的文件才成为视频输入。

## 1. 先拆动作状态，再决定图数

用动作规划说明准备、关键转折、结果和连续轨迹，再对照已选模式与现有素材。每张拟补图回答：缺什么、当前工具如何使用这张图、不制作它会留下什么不确定性？审阅用图可以只作布局说明。

| 当前情况 | 优先设计 | 数量的含义 |
|---|---|---|
| 模式接受身份/造型参考，现有素材与动作描述已足够 | 直接复用选定参考 | 新增关键帧可为零；不等于零输入图 |
| 需要明确开场或终点构图，现有图可兼任 | 复用相应画面，按真实缺口补图 | 首帧或起止图是一种控制方式，不是所有变装的默认套餐 |
| 接触或转折决定动作是否成立 | 起点＋必要动作锚点＋结果 | 三张是一种可能，锚点可先只是审阅示意 |
| 换装发生在同一动作的某个切点 | 切前与切后匹配状态，按需要另设开场/结尾 | 两张匹配帧服务切点，不能拿开场与结尾冒充匹配帧 |
| 多段动作、景别变化或较大空间位移 | 先按因果动作拆镜，逐镜决定锚点 | 不把整片强塞进一对差异过大的起止图 |

这些是选图方法，不是固定二/三/四帧套餐。用户限定两张时，可让两张用于关键切点，其他状态用动作设计或已有素材说明；仍不可行则简化机制并明确剩余限制，不暗中补图。

## 2. 先定画面，再做高完成度图

先从既有母版、场景原帧、粗略姿态草图中确定构图，必要时在授权内做少量布局候选。候选数量与最终帧数分别记录；没有制作授权时只交布局与图片编辑计划。基准帧可先选最能体现成片吸引力的结果画面，再派生起点和动作状态，不强制先制作开场；避免等全部图做完才发现整体画面方向不合适。

每个画面至少明确：景别与机位、人物在画面中的位置和尺度、视线/姿态、手或脚的接触点、前中后景、主光来源及服装展示重点。选有画面吸引力、能表达动作的构图，避免将角色三视图的正面陈列姿势直接复制为所有关键帧。关键动作在近景画外时，调整动作或构图；不为检查画外足部强制增加全身交付。

同一镜头共享空间基准：地面线、固定家具/门窗、人物初始落点、主光方向和机位。换景或换机位需有明确镜头设计；人物随动作移动时保留轨迹依据，不要求所有帧位置完全相同。

有接触/承重动作时，在已有交接里补一条对应关系：角色哪只手/脚（及画面方位）→接触什么→向哪里移动→何时释放或转移。逐图沿肩—肘—腕、髋—膝—踝检查实际可见链条，不能只看抓点在画面同一侧就认定同一只手。起止叙事状态可以不同，持续接触的肢体身份和道具关系必须相容；真要换手、换脚或重新抓握时明确过程。

检查起点是否给主动作留出行程，以及道具移动范围与身体/抓握行程是否相容。短距离拉动若需带来较大位移，应有可解释的滑行、释放再接触或其他结构；设计了连接不等于动态已实现，中间过程未有图件约束时明确列为待验。

换装方式也要能在图件与计划中成立：直接变化保留身体与空间锚点；遮挡揭示检查覆盖范围及进出路径；匹配剪切检查切前/切后状态。只有开场和结尾时，不将它们称为已完成切点匹配。关键瞬间未由图片约束的部分列为动态待验，不靠“强物理感”补证。

## 3. 原身份与造型持续生效，共用合格的场景基准

每次图像调用分清原身份、本帧对应造型、场景/布局和编辑目标。需要先做一张场景基准时，只有核对合格的内容供后续复用；从变装后画面派生变装前画面，仍以变装前原图决定其发型、服装、配件与可见结构。原图与中间图有冲突时先修基准，不能把原身份来源降成“只供衣服”来保住中间图的新形象。

- 每次只改当前帧需要的变量，如姿态、服装或照明；保留范围写成可核对的画面内容。
- 小问题优先局部编辑；大幅转身或透视变化需要新的姿态/布局依据，不能靠蒙版换衣强拉完成。
- 围绕共用干净基准派生各帧；相邻帧可提供动作或布局，但不逐代替换身份与造型来源。需要修订时合并已知差异，回到原参考及最近合格基准处理；这与角色素材扩展的派生修订规则（可选独立 Skill，未分发；需另行取得合法来源，缺少时不执行该分支）共用同一原则。
- 当前图片工具支持姿态、深度、边缘或区域控制时按其真实能力使用；没有这类控制时，用简明姿态/布局参考与图像编辑表达，不把“ControlNet”写进提示词冒充控制。
- 特效、颗粒与泛光最后加入；先解决脸/面具、人体、接触与构图。光效强度以主体和服装仍可读为限。

每帧交接：实际输入及各自职责 → 原身份与本套造型版本 → 场景/布局基准和编辑目标 → 本帧动作、构图及允许变化 → 输出用途。核对这些职责在真实工具提示词中未被改写，并真实附带所选参考；“沿三视图”或`@图N`文字不能替代附图。

## 4. 每帧与整组分别验收

| 检查层 | 必须实际查看的内容 | 不合格时 |
|---|---|---|
| 形象 | 对照三视图：身份、年龄感、比例、固定特征；前后服装职责正确 | 回到原参考修受影响部位 |
| 画面 | 焦点、层次、轮廓、服装展示、肤色/材质、光比与背景关系 | 调构图或光线，不堆质量形容词 |
| 动作 | 重心、关节、接触、遮挡路径、此刻是否真能承接前后动作 | 修姿态/布局；必要时补有用途的锚点 |
| 连续性 | 并排查看全部帧；核对实际左右肢体、接触对象、支撑、运动方向、尺度/透视，以及换装机制要求的锚点 | 无解释的换手/换脚、抓点跳换或不相容空间先修图或动作连接，不放入待生成输入 |

每帧留下简短的具体结果：对照了哪些源图、可见保持项/差异、是否影响本帧用途及修复位置；整组另查匹配关系，局部修订后重看相邻图与正文。可用一张紧凑检查表，不批量写相同的“已目视检查”作为结论。身份、本套造型、人体或必要连续性失败时，该帧相关用途暂不可用；其他合格部分与旧版本保留。技术通过、审美待选与用户采用分别记录。

可按计划时长排列已有图做静帧预演，检查信息顺序与停顿；这种预演只验证编排，不证明衣料惯性、遮挡或身体运动已经成立。进入视频前列明剩余动态风险及本次实际采用输入。
