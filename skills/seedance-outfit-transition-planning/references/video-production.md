# 视频输入选择与制作验收

在决定视频实际输入、补图范围或整片制作/返修时读取。先选择模式和参考职责，再决定是否制作关键帧。执行、绑定、下载和剪辑交给对应工具；当前任务的停止点与费用范围继续有效。

## 1. 选择当前入口、模式与生成单元

本组使用Seedance。按[共用合同](../../seedance-prompts/references/contract.md)确定原任务渠道与当前执行入口，读取实时模型目录、schema和素材约束；没有选定入口时沿当前项目，不静默切换渠道。只规划时可给标明依据的条件方案，不上传、不提交；模式未核实的限制明确留待执行前验证，不为猜测的槽位先做整套图。

按可完成的因果动作决定单镜或多镜。短版可为一个连续动作；长版可单镜，也可将准备、主要变化、结果展示分开。每段写起始状态、主要动作、结束状态和连接方式；镜头数不等于输入图数或收费任务数。

单镜更适合空间和人物位置连续、变化路径明确的动作。多镜或分段适合揭示点需精确切换、前后画风差异大、单条需要同时完成多种独立动作的情况。分段是制作选择，不自动扩大任务数量；先列所需片段、复用部分和总费用范围。用户要求一条且只批准一条时，优先简化动作与变化。

### Seedance参考模式

模式能力以当前Seedance渠道和CLI真实暴露的入口为准；家族模型说明不代表当前适配器实现了全部功能。

交接注明已核对的入口/能力、输入职责、实际约束与剩余自由度；只有规划时记录待核项，不为补能力字段创建远端草稿。准确首尾或切换时刻需要实际槽位或剪辑实现，缺少控制时调整机制或制作路线，不用多传图或正文命名冒充硬约束。

| 需求 | 可核对的模式 | 不能混淆的点 |
|---|---|---|
| 沿已有角色/造型，在新场景表演换装 | 全能/多模态参考 | 先评估原三视图/已有视角能否提供身份与前后造型；文字安排场景与动作，必要时另补构图图 |
| 从一个确定画面自然延伸 | 首帧图生视频 | 具体画面用作开场；三视合板是角色参考，不直接当作单人开场 |
| 从兼容的起点连续到达确定结果 | 首尾帧模式 | 只有实际首/尾槽位支持并绑定后才是模式约束；仍需动态验收 |
| 角色、服装、场景、动作与多个画面锚点分工 | 全能/多模态参考 | 参考用途须逐项映射；文字称“末帧/中间帧”不构成硬性逐帧锁定 |
| 前后片段在换装点精确连接 | 分段生成＋剪辑匹配 | 各段模式与费用单列，切点仍查方向、姿态、光照和运动速度 |

模式是否互斥按当前Seedance接口与CLI校验；网页按当前控件能力核对，不继承其他平台的互斥假设。不要把互斥的槽位写成一个已支持的请求，也不把模型能力误写成工具已实测。

## 2. 从已有素材选择实际输入

先列身份源、前造型、后造型、场景/动作参考，再评估哪些进入当前模式。一套三视图可兼供身份与对应造型；两套造型共享身份，但各套发型、衣物、配件分别保留。多视合板说明为同一角色的多个角度；需要单视角时优先使用原图中已有视角，仍保留来源关系，不据未见角度新设人物。

| 素材状态 | 决定 |
|---|---|
| 现有原图适合模式的身份/造型参考 | 直接复用，并在提示词说明各图的用途和造型出现顺序 |
| 身份/造型足够，但场景或接触关系需要确定画面 | 保留原图职责，只补对应场景/动作缺口；新增图按模式作为辅助参考或具体画面 |
| 需要精确起止或切前切后控制 | 选择工具真实支持的槽位或分段剪辑；仅有多参考时，将精确时点列为待动态验证，不以图的张数代替控制能力 |
| 模式容量或输入类型不允许原图与关键帧同时传入 | 按本任务最重要的控制目标取舍，说明原图未上传的原因；派生图须先通过原身份/造型对照，原图仍是制作与验收依据 |

生成新图前交接一份简短清单：文件/版本、原图或派生图、职责、实际输入/仅供制作/仅供审阅、保留或排除理由。若足够则新增图数为零；确有缺口时进入[关键帧质量流程](keyframe-quality.md)。已经展示并获准的方案直接续作，只有改变角色、输入策略、数量范围或停止点时才显式说明变更，不例行要求再次确认。

## 3. 提示词与交接

用户审阅稿沿用精简中文`@图N`正文，参数与过程说明放外面。执行稿按实际工具映射引用与格式：当前工具直接接受自然语言时保留该稿；明确需要官方结构化重写格式时，另存机器执行版并回读，不把长协议强塞进用户审阅稿，也不把中文、时间码规则或已确认声音方案静默改掉。

本地Seedance写作采用参考职责分工：人物/造型/场景等可复用内容，与某一具体时刻的画面锚点分别定义；编号全程一致。主体表演、物体状态、光线与镜头沿时间发展，而非重复静态图片描述。执行稿保留分镜已确定的摄影决定与物理因果，按主入口第5节做精简回对；两张角色参考只解决身份/造型时，构图和动作仍须在正文中表达。需要分镜时间结构时在计划或适配版中完整覆盖当前片长。

“到生成界面停下”按实际交付解释：后台prepare完成意味着取得输入/参数/报价的读回；可见页面交接还需要该页面实际保留并可供用户查看。当前Seedance执行器是否提供可见页面需实际核对；后台准备完成不代表浏览器页面已经打开。用户明确要可见页面时使用当前可用且获准的可见入口，并在提交前停下；若没有这种能力，交付已完成的素材与后台读回，明确页面交接仍未完成，不冒称已打开。已有不抢桌面限制仍生效，歧义只澄清交付方式，不重问已确认内容。

完成一个阶段就更新原执行记录中的实际图件、输入顺序、已绑定/未绑定和下一步，旧规划保留为快照。中断后先核对当前文件与任务标识再续接，不把旧“待制作”记录当作重生图依据。

## 4. 执行与后期

1. 交接采用图件、顺序、引用职责、模型/模式、规格、声音、当前报价与任务范围。只生成用户已授权的部分；状态不明查询同一任务，不另开重试。
2. 取得实际视频后先检查变化前、变化中、变化后的连续运动，再决定剪辑。抽帧帮助定位问题，不能代替完整观看；静帧预演、上传回执、生成完成均不能代替成片通过。
3. 可用素材优先精剪：缩短等待、去掉多余静止、匹配动作方向与速度；保留必要起势和结果停顿。确需补镜时只补受影响段，重新核对对应范围与费用。
4. 音乐、音效与表演的连接单独检查。原版音乐或固定面具等要求沿当前项目；生成音轨、备选曲段与最终已核听音轨分别记录。没有选曲不编造拍点。

## 5. 动作、换装与节奏的实际验收

把计划和实测分开记录：主要动作开始 → 变化开始 → 新造型可读/变化完成 → 制动完成 → 结果段结束。时间取自实际视频；事件重叠可如实记录，没有实际视频则写待验，不从关键帧数或计划表推算。

- **动作连续性：** 连续查看转场附近的肩肘腕、髋膝踝和道具轨迹，核对计划中的抓握/支撑、释放与重新接触。无设计的换手、脚滑、接触跳换或运动反向不通过，定位到具体时段。
- **换装瞬间：** 按所选机制验收。直接变化检查替换是否清楚且人体运动延续；遮挡揭示检查变化是否发生在所需遮挡范围内；匹配剪切检查切前后姿态、方向和速度。不能用“确实换衣服了”代替机制成立。
- **摄影与物理表现：** 对照分镜和实际连续画面，检查相机高度/朝向、人物与道具位置/尺度、空间光线是否实现，以及本动作的支撑转移、接触或运动反馈、身体制动和必要材质延迟是否可见。分别记录偏差时段；动作做完、身份稳定、固定机位或参数正确都不能单独判这一项通过。没有实际连续审片时标待验。
- **节奏：** 查看准备是否持续提供动作信息，变化是否可读，结果是否有必要的反应和停顿。标出重复站姿、无目的等待或余摆已经收尽后的冗余片段；先评估精剪，仍需保持已确认成片时长时重排现有可用内容，确需补镜再按范围执行。没有适用的统一秒数或静止占比阈值，不为凑表演强加多余动作。

每项留实际观察与处理结果：通过／需修及位置／待验。图文审查只验证可执行设计；抽帧仅帮助定位，完整连续播放和适用声音核听未做时不能标成片通过。

## 6. 验收与返修定位

| 发现的问题 | 优先修哪里 |
|---|---|
| 脸/面具、体型或服装结构漂移 | 原身份/造型参考、图片编辑范围与绑定职责 |
| 单帧好看，连起来空间或姿态不接 | 镜头基准、动作锚点、匹配帧或片段切点 |
| 形象稳定但只有缩放、慢漂移 | 主体动作与镜头运动分开描述；删减同时发生的独立事件 |
| 闪烁、衣物融化或背景跳动 | 连续查看具体时段，检查参考冲突与变化路径；必要时局部补镜 |
| 转场过早/过晚、结果展示冗长 | 先精剪时间轴；无法靠现有素材解决再补生成 |
| 画面技术合格但缺少吸引力 | 返回主题、构图、表演与节奏，不能只靠加分辨率或更多帧 |

检查身份稳定、背景连续、动作幅度、运动平滑度、闪烁和整体画面质量，但不把自动指标或相似度当成审美与物理通过。最终交付包含实际视频、所用参考与版本、可复制提示词、必要声音来源、发现的问题和采用状态；没有实际生成时仅交对应计划与素材，注明动态未验证。
