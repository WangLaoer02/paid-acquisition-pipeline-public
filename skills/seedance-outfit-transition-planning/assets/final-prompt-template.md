# 成品正文模板

只取适用的一版写成自然语句，替换括号内容后删除本说明。用户审阅正文不带标题、总时长、模型、分辨率、审核状态或时间码；工具确需的结构化执行版单独保存。`@图N`按实际输入映射，注明同一人的身份与前后造型。角色参考只承担外观时，直接用文字描述开场与结尾；仅在选中具体画面图时引用它作为锚点。没有相应输入就删去引用，不为填模板新生成起止图。

压缩前从分镜取出本镜的摄影决定（机位、人物/道具布局、尺度与空间光线）及物理因果（支撑或启动、接触反馈、制动与必要延迟）。用动作句合并这些信息，删外观重复与解释；固定镜头保留构图，轻动作保留启动和收势。写完与分镜回对，不能只剩动作名称。

## 快速版形状

〔拍摄方式/画风、具体场所和光源〕，〔本镜机位与人物/道具布局、尺度、必要空间层次；固定或有目的的运动〕。〔身份及前后造型引用〕。主角〔可见支撑或启动〕，〔触发及接触/运动反馈〕；〔连续变化并承接结果造型〕。〔身体制动、必要衣发/道具滞后与结束画面〕。〔一句确有必要的角色约束〕。

## 叙事版形状

〔拍摄方式/画风、具体场所和光源〕，〔本镜机位、人物/道具位置和尺度、空间层次〕。〔身份及前后造型引用〕。主角〔起始支撑或运动状态及期待〕，〔有目的的准备或表演〕。

〔主要触发及变化开始的可见事件〕，〔按选定直接变化、遮挡揭示、匹配剪切等方式完成换装，承接结果造型与必要画面锚点引用〕。〔接触或运动反馈、身体制动与必要延迟、提供新信息的反应及收稳〕。〔沿已定构图固定或有目的地运动；切镜时保留方向与动作连续；一句确有必要的角色约束〕。

参考映射与“拟引用，未绑定”放在正文之外；未提供对应图片时保持草稿，不保留空引用冒称成品。三视图、场景原图、姿态示意、成片关键帧先按职责筛选，只有当前模式选中的文件进入实际编号。
