# Seedance 变装素材规划

把变装想法变成有明确前后反差、触发事件和可信动作的制作方案。创意、风格和动作是主体；角色细节由参考图承担。

本入口负责当前要求、创意、参考选择和提示词。只要规划时交付对应计划；已授权制作时，携选定输入和必要缺口交给角色、视频或平台Skill，继续到用户指定的停止点。调用下游不重新决定角色、素材数量或交付格式；读取本入口也不把已授权制作退回只规划。

视频按[Seedance共用合同](../seedance-prompts/references/contract.md)处理默认、引用与执行；当前任务已采用的精简正文继续适用。

## 1｜选择版本与当前任务

| 任务 | 只读取对应分支 | 结构 |
|---|---|---|
| 5秒版 | [快速变装](references/five-second.md) | 动作立即开始，一次强触发，完成变化并留出收稳 |
| 15秒版 | [叙事变装](references/fifteen-second.md) | 准备建立期待，主要触发完成变化，再展示动作后果与结果 |

用户指定哪版就做哪版；要求两版时用同一创意分别编排，不把短版放慢充长版。已在续接的任务沿用其确认时长；未指定的新成片在当前最终时长默认内选择适当编排，5秒版仅用于明确短镜或已确认任务；生成片段规格另按共用合同，不为此增加测试生成。分支名和参数留在计划/文件名中，成品提示词正文不写“5秒”“15秒”、总时长、分辨率、模型或平台操作。

从原项目当前状态及其指向的最新执行记录恢复最新用户修改、角色与造型来源、数量上限、声音和停止点，再读图文快照；旧“未生成/提交0次”仅说明当时阶段。先确认已有任务与产物，再按范围进入图文修订、审片或返修；仅图文任务不强制审片。区分本次交付的是故事、分镜、提示词、图件、后台准备还是可见生成页面。当前要求优先于导演默认套餐；时长分支不决定图数。沿原清单维护当前阶段，历史规划标为快照或指向当前执行记录；简单整理直接交聊天。

**角色默认沿用用户已生成的三视图。** 优先使用本轮指定的角色与版本，其次沿用当前项目已采用版本；实际查看后记录来源和用途。脸、年龄感、体型与固定特征沿身份源，发型、服装和配件按前后各套造型分别对应；只变化本次允许的内容。仅供借衣服的图仍只供衣服。未指定角色时先查当前项目和已有素材，多套无法确定或未找到时保留待选/缺口；只有明确要求新角色时才新设身份。“已生成”“本片指定使用”和“角色库已采用”分别记录。

## 2｜先定拍摄方式、场景与反差

先交代为何从前造型变成后造型、观众会记住什么，再选择转场。只要故事背景时先给简短情境；要求一句话就用一句话交代前后，要求反转时让变化本身兑现反转，再按后续要求展开分镜。新意可以来自情境、身份反差、表演或揭示方式，说明本案的新意即可，不强求每条发明新转场。历史案例仅在续接作品或机制已选定、需查细节时读取。

需要形成分镜、提示词或实际输入方案时，按导演[成片元素与控制分工](../seedance-cinematic-director/references/element-control-contract.md)覆盖适用元素、分配主依据与实际控制，再写具体画面：**拍摄媒介/画风＋真实场所与光源＋变装前状态→触发事件→变装后状态**。一句背景任务不展开全表。三视图、场景、动作和摄影分别承担职责，沿原计划记录固定项与变化项。

- 拍摄表达使用能影响画面的词，如真实手机拍摄、业余手机随拍、固定支架拍摄、专业摄影棚实拍、专业广告摄影或已选CG画风；不只写“电影感、高质量”。这些是目标观感，生成场景不冒称真实拍摄。
- 场景写具体空间，例如摄影棚工作区、白色背景棚或窗边房间，并说明主光从哪里来。手机拍摄不自动等于晃镜；需稳定对接时可以手机固定支架拍摄。
- 从造型、姿态/表演、人物处境和光照/成像中选择服务主题的反差；喜剧可落在期待与结果，画风变装可落在成像变化。保留角色身份、身体比例和必要空间锚点，不要求每项同时改变。
- 景别和机位为动作服务：在分镜中确定相机高度与朝向、人物位置与画面占比、动作留白、前后景及主光方向；只把影响本镜的决定写进正文。固定机位同样需要构图，单镜也可以有明确的空间层次。让选定视角看清本动作的接触、支撑或制动；近景用可见身体反应表达，不为说明受力强行露出全身。按主题、动作可读性与工具能力选择动作匹配、姿态/构图呼应、光照变化、遮挡揭示或其他有依据的机制，各类机制没有默认优先级。

**通过条件：** 前后造型与动作状态能表达选定反差，变化路径可解释；已有起止画面时缩小检查其可读性。按主题选择有效变化并保留连续性锚点，未达到时先调整设计，不以同时改变机位、人体尺度、场景和曝光来堆叠反差。

## 3｜先选视频输入，再确定素材缺口

需要找原图或续接案例时才查[素材参考索引](references/material-sources.md)对应部分。选择后实际看图/看对应片段；只有旧文字或路径时注明未本轮审图/审片。

| 参考职责 | 决定什么 |
|---|---|
| 用户已有三视图及对应角色母版 | 按第1节持续提供身份、年龄感、体型和固定特征；可作为视频角色参考，也可供必要的图片编辑 |
| 前后各套造型图 | 分别提供该套服装、发型、配件与材质；同一套三视图可兼供身份和造型，按职责注明 |
| 画风原图 | 成像、光比、色彩与渲染；不迁移其中人物、道具和场景 |
| 场景图/真实原帧 | 空间、光源和接触点；静态图不证明动作已发生 |
| 动作原片 | 具体动作与时间码；原创连接明确为设计，不冒充原片复现 |
| 派生关键帧/布局图 | 已核对的场景、构图、姿态或具体画面锚点；原身份与对应造型仍由其来源决定 |

参考冲突按职责回到原来源处理：布局图不能改身份，另一套造型不能改当前套装；已生成的中间图不因版本更新而接管这些职责。必要时修正派生图，再使用其已合格部分。

为后续制作规划实际输入时，先读[视频输入选择与制作验收](references/video-production.md)并核对当前入口；只写一句背景时不加载。先把已有三视图列为身份/造型参考候选，再按模式选择原图、其中已有视角或配合必要画面图。说明原图最终直接输入、仅供制作还是暂不使用及原因；“生图时参考过”不能替代这项视频输入决定。模式尚未核实时给条件方案，先完成不依赖该模式的工作。

清单记录来源、版本、职责、采用依据、复用/局部修改/待制作/退出本次输入，以及审阅交付和拟视频输入的区别。候选与推测视角保留标签，最高版本号不能代替采用。

### 只补当前模式需要的图

已有角色/造型参考和动作描述足够、模式支持相应用途时，可以不新增关键帧。需要确定构图、接触或精确切点时，才补起点、结果、动作锚点或匹配帧；每张说明它消除的缺口、在当前模式中的用途，以及现有素材为何不足。故事时刻、审阅分镜、新增图件和实际上传数量分别决定。用户给定上限时，在上限内简化动作或调整剪辑。

确需制作或修订图件时读[关键帧设计与质量流程](references/keyframe-quality.md)：以原身份、对应造型和共用场景/布局为依据派生，并逐帧核对。制作范围与费用沿当前授权，不为验证规划额外生成测试视频。

`@图N`按本次实际输入顺序列在正文外，每张注明身份/造型、场景、动作或具体画面锚点的职责；两图只是可选情况。局部修订只更新受影响的图和依赖，旧图保留历史、不进入当前输入。

## 4｜让动作与变化可信

围绕选定创意安排主要触发、铺垫与结果。先选本动作可见的物理因果：身体靠什么支撑或怎样转移重心，接触/启动怎样改变运动，停止后衣发或道具怎样延迟并收稳。轻触、转头和转身也有启动与制动；需要明显发力时再展开张力、压缩或回弹。只写实际发生且能拍到的环节，反应或声音触发不强加拉扯。幻想变化可以保留，但身体、接触和材质仍按所选规则连续响应；物理感不由特效光带替代。

触发动作与换装方式分别确定，说明从哪个可见事件开始、到哪个状态完成：身体可见的直接变化要交代衣物替换及运动延续；遮挡揭示要覆盖所需变化区域；动作匹配剪切要有兼容切点与可执行剪辑路线。其他机制按自身依据说明，不只写“顺着发力切入新造型”。改变光照时说明光源依据，白闪不代替接触与受力。

若制作起止帧，用叙事状态差异说明变化；切换匹配帧则可以同姿态、同接触点。接触/承重动作明确角色哪只手脚、画面方位、接触对象、移动方向及释放/转移时机；区分角色左右与画面左右，图与正文保持相容。具体检查沿[关键帧质量流程](references/keyframe-quality.md)，不为画外部位补全身图。

选择了关键帧时，让相应接触、支撑或制动状态可见；仅使用角色参考时，这些过程由动作规划承担。视频中的速度、惯性和接触连续仍须实际生成后验收，静帧不能证明动态通过。

## 5｜写精简成品提示词

使用[成品提示词模板](assets/final-prompt-template.md)，先完成第2节构图与第4节动作设计，再按下列规则压缩正文。精简删重复外观、形容词和过程解释，保留本镜的摄影决定及物理因果。共用要求直接读[本地Seedance合同](../seedance-prompts/references/contract.md)；本专项的精简正文优先于通用时间轴展示习惯。项目附加约束从本地当前记录读取。

**正文组织：先建立拍摄空间、光线与必要构图，再对应@图N的前后状态，沿动作因果写触发、变化和收稳；有运镜时随动作写清，一句必要角色约束收尾。构图已说明的内容无需末尾重复。**

- 本用户成品稿使用 `@图N`，编号随实际输入数量变化，按已列映射承接用途，不机械写成两图变换，也不逐件罗列服装。动作过程用可见事件衔接相应参考。
- 开头必须有具体拍摄方式/画风和真实场景表达，并使后续风格转折与图件一致。CG与实拍质感如何变化属于创意，不用“全片真实摄影”覆盖掉已选CG结果。
- 用正向动作叙述。身份、背景、服装等重复禁令留内部检查；固定Kig面具确需说明时只保留一句“面具表情固定，由头向与身体表演”。
- 成品稿只保留画面、动作、镜头、声音和必要创作限制；时间轴、参数、检查过程、采用状态、缺项及授权写在正文外。不要把整个制作说明粘进prompt。
- `@图N`是本次交付的参考标记，未上传时在正文外标“拟引用，未绑定”。实际即梦执行由工具Skill生成并回读原生reference part，不把字面@引用当成已绑定；其他平台按其真实引用方式适配。

**通过条件：** 将精简稿与分镜对照：仍能据正文摆出所选机位、人物与道具关系，并读出本动作的支撑/启动、接触或运动反馈、制动及必要延迟。已设计且决定观感的要点在正文有可见表达；“固定全身”“自然运动”“有重量感”不能代替这些决定。字数紧时合并因果句或减少事件，保留因果与构图。正文没有时长参数，@编号对应实际选定图件；这只通过文字设计，动态仍待成片验证。

## 6｜按需联动，回到原停止点

交接顺序为：当前要求与原素材 → 创意和必要分镜 → 当前视频模式与输入清单 → 只补实际缺口并验收 → 精简提示词与平台准备 → 按授权生成、剪辑和动态验收。只执行本轮需要的部分；复用已读分支。后台准备和可见页面交接按[视频制作](references/video-production.md)分别验收。

| 实际缺口 | 联动入口与输出 |
|---|---|
| 动作、场景调度、机位或切点 | [seedance-cinematic-director](../seedance-cinematic-director/SKILL.md)，只补当前分支需要的导演决策 |
| 母版/局部造型修改 | character-asset-extensions（可选独立 Skill，未分发；需另行取得合法来源，缺少时不执行该分支），交接原图、允许变化和受影响图件；只有明确制作指令时生成 |
| 已有三视图确有缺失或本轮明确要求同步修订 | cg-sheet-consistent-variation（可选独立 Skill，未分发；需另行取得合法来源，缺少时不执行该分支），交接既有角色与版本、允许修改的造型及受影响视图，只补本次必要缺口 |
| 暖灰实拍感或逆光CG | warm-gray-film-anime（可选独立 Skill，未分发；需另行取得合法来源，缺少时不执行该分支）、soft-backlit-cg（可选独立 Skill，未分发；需另行取得合法来源，缺少时不执行该分支），只加载所选画风原图，拍摄媒介按当前创意说明 |
| 真实场景/机位素材 | character-location-photoshoot（可选独立 Skill，未分发；需另行取得合法来源，缺少时不执行该分支），选具体原帖/照片，不把照片当动作来源 |
| 后续视频制作与验收 | [seedance-character-shortvideo-production](../seedance-character-shortvideo-production/SKILL.md)，接收本次图件映射、风格、选定分支和精简正文，保留这些交付要求，不恢复成长篇服装/禁令列表 |
| 后续平台执行 | `dreamina-canvas-cli`（dreamina-canvas-cli，`SKILL.md`，按已安装 Skill 目录定位），当次另行核对真实引用、能力、账号与报价；当前只规划时不操作远端 |

按所需分支交付关键帧/素材链接、可复制成品正文和简短说明；详表放[规划交接模板](assets/planning-template.md)。用户只要一版就只交一版。旧失败输入与平台拒绝原样留档，原因未知不猜，状态不明先回查，不据旧授权重试。

方法依据与适用边界见[GitHub一手来源与取舍](references/github-methods.md)，仅在查证方法或评估新增工具时读取；仓库中的控制能力不自动成为当前图片工具或Seedance执行入口的可用功能。

## 可选工作台

只有用户要求记录、从工作台排队任务续接，或当前项目已选用工作台时，才读取 `seedance-prompts` 的 `references/studio.md`，沿同一 task/run 保存进度与候选。普通创作、采集与字幕直接在当前任务交付；工作台未配置不阻塞这些工作，也不替代原项目状态。
