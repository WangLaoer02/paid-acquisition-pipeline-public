# 状态汇报

## 用途

用户问这个 Skill 是否可用、运行状态、用了哪些数据、是否触达外部系统时，按本文件汇报。

## 汇报字段

```text
Skill：rongyao-material-analysis
路径：`${AGENTS_SKILLS:-${CODEX_HOME:-$HOME/.codex}/skills}/rongyao-material-analysis`
运行方式：文本分析，无后台写操作
本次加载：...
输入来源：...
外部系统：未触达 / 读取飞书 / 读取荣耀后台数据
输出内容：...
数据缺口：...
不可判断项：...
```

## 规则

- 不报告凭证、Cookie、Token、飞书完整敏感标识。
- 如果只是分析用户给的数据，写“外部系统：未触达”。
- 如果数据来自飞书文档或荣耀后台，只说明来源类型，不复述敏感链接。
- 如果缺字段，必须列出缺口。
