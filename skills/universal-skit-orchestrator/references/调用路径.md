本页是小剧场创作 Skill 的**逐级调用目录**。每条路径都是根据本次目标可选择的工作流程，**不是后台自动执行已发生的记录**。有 Notion 访问权限的助理应先读取母 Skill 再按条件读取对应专项；没有接入权限时，用户可以提供各页面内容。

## 零级入口（所有路径共同起点）

[小剧场创作母 Skill｜通用元协议 v2.0](https://example.invalid/optional-authoring-source) → 判断本次用户目标 / D1–D6 → 选择主专项 → 可选辅助模块 → 产出 → 按适用标准验收。

- **现有目录总入口**：[查看关联页面](https://example.invalid/optional-authoring-source)
- **新专项标准接口**：本母 Skill 子页面《子 Skill 接入模板》
- **原偏心 Skill**：[查看关联页面](https://example.invalid/optional-authoring-source)（权威原始规则：[查看关联页面](https://example.invalid/optional-authoring-source)）

## 路径 A｜只发散创意

**调用顺序**：母 Skill → D1 目标+D2要素+D3体验 → 选择题材/机制专项（存在时）→ D6去同质化检查 → 输出多条差异化创意。

**适用**：「给我10个火影社会矛盾的新点子」「找荒诞的行为梗」，无需自动塞入完整剧情、分镜和买量卖点。

**可复制指令**：「调用小剧场母 Skill，任务=创意发散，给10个不同机制的火影社会矛盾创意。优先第一画面可理解，不强制偏心或反杀。」

## 路径 B｜写普通小剧场

**调用顺序**：母 Skill → 已有对应题材子 Skill / 无则通用创作 → 可选 [查看关联页面](https://example.invalid/optional-authoring-source)（确实需要完整叙事/连续性时）→ 剧本 → 验收。

**适用**：生活短剧、神话挑战、视觉喜剧、对话剧。注意：总导演强调 goal/conflict/twist，不应把其冲突结构强制应用于无冲突/氛围型作品。

**可复制指令**：「调用小剧场母 Skill，创作原创无台词视觉喜剧，只有一个笑点，不要强制冲突升级或反杀，直接输出动作剧本。」

## 路径 C｜火影偏心 / 双标 / 踩捧

**调用顺序**：母 Skill → [查看关联页面](https://example.invalid/optional-authoring-source)（以 [查看关联页面](https://example.invalid/optional-authoring-source) 为准）→ 火影设定与关系校验 → 剧本 → 专项验收。

**适用**：强让眼睛、资源分配、哥哥让弟弟、反向怪罪等结构。

**可复制指令**：「调用母 Skill + 火影偏心 v3.3，设定为鼬被要求把万花筒交给佐助。按专项写220–320字；不需要额外广告口播。」

## 路径 D｜信息流 / 游戏买量小剧场

**调用顺序**：母 Skill → 题材/机制专项（可选） → [查看关联页面](https://example.invalid/optional-authoring-source) → 实际游戏产品/卖点资料 → 剧本 / 变体 → 验收卖点与前文因果。

**适用**：用户明确提出游戏广告、买量、卖点、转化。3秒钩子、15–30秒等属于广告导演的局部要求，不能反推给所有类型。

**可复制指令**：「调用母 Skill + 信息流广告短剧导演，火影组队歧视题材，15–30秒，游戏卖点必须解决前文的战力问题；没有提供的具体数值不要编造。」

## 路径 E｜已有剧本转分镜

**调用顺序**：母 Skill → 锁定剧本和不可更改部分 → [查看关联页面](https://example.invalid/optional-authoring-source) → 镜头表 → 制作性验收。

**适用**：「把这个剧本拆成镜头」「我要站位/动作/镜头原因」。用户仅要求分镜时不擅自重写剧本。

**可复制指令**：「调用母 Skill + 分镜导演，把以下剧本拆成可直接用于AI视频的镜头表，保持对白和剧情不变，逐镜写明人物站位与可见动作。」

## 路径 F｜参考视频改编/严苛复刻

**调用顺序**：母 Skill → 解析参考视频 → [查看关联页面](https://example.invalid/optional-authoring-source) → LOCK / REPLACE / ADAPT → 复刻分镜 → 差异检查。

**适用**：「保留视频镜头节奏，仅改为火影角色」。用户要严苛复刻时，此专项优先于普通分镜导演的自由优化建议。

**可复制指令**：「调用母 Skill + 参考视频严苛复刻导演，锁定原片的构图、动作节拍、字幕位置，只将人物换成指定火影角色。先输出差异表再给分镜。」

## 路径 G｜分镜/剧本转 AI 视频提示词

**调用顺序**：母 Skill → 已确认的剧本/分镜/图片素材 → [查看关联页面](https://example.invalid/optional-authoring-source) → 按目标模型规则生成提示词 → 时长、动作、素材绑定校验。

**适用**：Seedance / 即梦等执行提示词。目标工具和项目要求优先；不要把该工具默认15秒上限当成所有小剧场永久限制。

**可复制指令**：「调用母 Skill + AI视频提示词优化 Skill，按已有镜头和角色参考图生成模型可执行提示词，不增删剧情，检查所有图片节点与角色映射。」

## 路径 H｜拆解、复盘、迭代

**调用顺序**：母 Skill → 原脚本/原视频/真实投放数据 → D2/D3/D4 拆解 → D6评价 → 按目标改写 → 多版本对比。实际业务效果只由用户提供的真实数据决定。

**适用**：「为什么这个剧本平」「有什么可复用的流量结构」「优化头3秒」。

**可复制指令**：「调用小剧场母 Skill，拆解原视频的内容要素、观众体验机制、信息组织方式和表现形式；提出3种机制上不同的改法，不仅仅换角色和台词。」

## 路径 I｜创建全新专项 Skill

**调用顺序**：母 Skill → 子 Skill 接入模板 → 确定职责、触发、六维映射、独有机制、输入输出、冲突和验收 → 创建新的 Notion Skill → 将其加入本调用索引。

**可复制指令**：「调用小剧场母 Skill 的子Skill接入模板，为‘神话角色极端挑战’创建独立专项。不要继承偏心规则，建立自己的体验机制和输出验收。」

## 规则优先级

安全与工具限制 ＞ 用户本次明确要求 ＞ 适用专项/可靠资料 ＞ 母协议通用原则 ＞ 可覆盖默认值 ＞ 经验性惯例。

只调用存在且相关的模块；缺失的专项明确说明当前按母协议处理，不把名字当作已经安装或已启用的能力。
