# 成片元素与控制分工

在制定制作规则、创意转分镜、选择实际输入或排查相互冲突时读取。主入口的小任务范围优先：内部按需核对，向用户只交本次所需内容。此表是导演决策分工，不是各平台功能清单，也不要求每行制作一张图。

## 1. 先覆盖内容，再选控制

沿导演主流程：表达目的/故事节点 → 人物与道具调度 → 构图、光线和声音 → 核对当前工具实际能力 → 选择现有输入与必要缺口 → 精简提示词 → 制作及验收。复杂故事写冲突与转折；服装展示也可只有“选择→变化→结果”，不强加完整戏剧结构。

每条片内部检查下表各项是否适用；没有对白、音乐、字幕或特效可以明确为无，不为凑齐元素新增内容。人物行对无人场景不适用。时长、画幅和分辨率属于交付规格，另行核对，不能代替内容设计。

| 元素 | 先决定什么 | 适合的主控制及补充 | 边界与验收 |
|---|---|---|---|
| 剧情与表达目的 | 观众看什么、为何变化、开始→转折→结果；每镜的作用 | 创意句、故事节点和分镜组织因果；剪辑落实信息顺序。提示词执行本镜可见事件 | 参考图不能自动提供动机。连续看成片是否读懂因果；展示片不必强加对白或反转 |
| 人物身份与前后造型 | 谁、固定特征、各阶段穿什么/发型配件怎样变 | 已采用母版/三视图作身份与各套造型源；工具支持时按相应用途输入。文字只补职责与出现顺序 | 身份固定与造型变化分开；场景、动作或画风参考中的人物不能接管身份。逐阶段对照原来源 |
| 场景与道具 | 空间布局、人物落点、物体位置/尺度/状态及可交互规则 | 场景原图/布局图/合格画面锚点管空间；简单新场景可用文字。道具状态和接触过程写入调度 | 场景图不证明动作发生。人物/道具是否够得着、能否遮挡、进出画及前后状态须相容 |
| 动作、表演与物理 | 起始支撑、路径、速度、接触反馈、制动和必要材质滞后 | 动作调度与因果文字；需要复现时用动作原片，只有实际支持才用动作/姿态控制；关键姿态图只补具体瞬间 | 静帧不能控制完整速度与受力。按连续画面查重心、接触、惯性和收稳；幻想机制与身体/物体规则分清 |
| 摄影构图与运镜 | 相机高度/朝向、景别、人物占比/位置、留白、景深、固定或运动 | 分镜先设计；已有合格画面/布局参考提供可视依据，首帧等真实槽位约束具体画面；文字或可用相机控件说明运动 | 三视图不承担镜头构图；固定机位也须设计。通用参考或文字角度是引导，不能冒称精确摄影控制 |
| 光线、材质与画风 | 主光在空间中的来源、软硬/明暗、材质响应、统一成像目标 | 场景/画风依据和合格画面锚点提供外观，文字说明光源与变化；调色/合成处理需精确保持的效果 | 画风参考只迁移已选属性，不带走人物/构图。换机位时重新换算光在画面哪侧；物体材质不随运镜无故改变 |
| 声音与文字信息 | 对白、环境声、动作音、音乐、字幕分别是否需要 | 选定音轨/配音、音效与字幕素材；适用时使用已核对的原生声音能力；后期负责准确同步、文案和版式 | 模型能产音不等于已选音乐。音画实际核听；需准确UI、文字或数字时用真实素材/后期，不依赖生视频随机写字 |
| 节奏、转场与成片连接 | 每段新增信息、变化点、停顿、镜头连接及结尾状态 | 分镜时间表作计划；单镜提示词描述事件先后；多镜用兼容动作/画面衔接，剪辑决定准确切点和节奏 | 计划时间码不等于逐时点硬控制；镜头数、参考图数、付费生成数分别决定。成片检查实际时长、连接和信息推进 |

## 2. 控制方式按能力分层

- **制作依据**：母版、三视图、场景/风格原图、动作原片决定本片采用什么，未实际输入时只是制作或验收依据。
- **生成引导**：自然语言和已绑定的通用参考影响结果；为各图标明职责与顺序，不假定模型会隔离掉所有无关内容。
- **实际输入/参数约束**：已核对的首尾帧槽、动作或姿态输入、相机控件、时长画幅等。各自只控制其暴露的范围，仍需验收，不保证中间运动必然正确。互斥槽位不可假装同时支持。
- **后期确定控制**：剪辑、字幕、配音、合成用于准确时间、文案和可编辑层；后期不能凭空补回未拍到的可信动作。

先复用足够且兼容的已有素材；只有某项重要需求缺乏有效依据或控制时才补图/补镜/换方法。每项写清“目标状态｜主依据及允许变化｜实际控制及用途｜剩余不确定性｜验收”。文字不足时增加的应是对应控制，不是更多禁令；未授权的制作留计划。

## 3. 冲突按职责和状态解决

1. 当前用户要求确定目标与范围。每项指定一套采用依据，可由多文件协同；没有按版本号或新旧图片统一压倒所有其他来源的优先级。
2. 身份看身份源，各阶段服装发型看对应造型；场景看空间方案，构图看分镜/选定画面，动作看调度，风格看已选成像依据。跨职责发生冲突，先修派生图或减少不相容输入，再交给生成器。
3. 固定项与变化项分开：记录起点、触发、终点及须保留的连续锚点。“同一人”允许指定换装；光线变动需有场景依据。角色左右、画面左右、世界中的光源位置分别记录。
4. 同一属性的实际槽位、图件和文字保持相容。例如固定机位不同时写绕拍；主图是俯拍时不靠正文要求同一开场低机位；蓝白卡结尾留下就不能在另一段让全部卡消失。需要改变时说明发生过程、切镜或改输入，不把矛盾指令一并提交。
5. 每个生成单元围绕一个主要目标、一个主导相机行为组织运动；准备、动作后果和收势可服务同一目标。若独立事件挤掉接触反馈或结尾，先删减/重排；确需拆段则重新核对任务数与费用。不要把动词数量当镜头数量。
6. 精简时保留剧情因果、已选构图、物理反馈和结束状态，删重复描述与过程解释。图件确已承担的静态信息可缩写为职责；未被输入承担的设计不能省略。变装正文继续沿专项模板，不恢复成长篇通用协议。

## 4. 完成依据

文字阶段：元素有适用结论、依据和实际控制，各项拼成一条可拍的因果链，引用/左右/状态/镜头没有互相冲突。小任务用一张简表或原分镜字段即可，不另建项目主控。

成片阶段：以同一组目标回看完整画面与声音，分别记录内容、身份造型、空间、摄影、物理、音画与节奏的实现情况。生成回执、规格正确、静帧好看均不能代替这些通过。未做的检查标待验，未满足的元素定位到相应控制环节修复。
