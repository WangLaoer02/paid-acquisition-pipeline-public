# 接B · 命名 · 上传｜同事使用说明

做完 A 段后，让 Codex 帮你：**从选B台挑 3 段合适的 B → 接好 → 按公司规则命名 → 出好上传清单**。你只需要看一遍成片，再到自己的后台账号里上传。

---

## 一、第一次安装（约 5 分钟）

需要：Mac 或 Windows 电脑、Codex（用**你自己的**公司账号登录）、Python 3.9+、FFmpeg。

1. 从飞书文档下载负责人发的 **团队配置 zip**，放在“下载”文件夹里（不要转发到群外）。
2. 拉取技能（任选其一）：
   - 让 Codex 做（推荐）：在飞书交付包「第一步：检查交付包」点 **复制给 Agent**，粘贴给 Codex。
   - 自己做：`git clone` 上面的仓库，进入 `ab-join-name-upload`：
     - **Mac**：双击 **双击安装.command**（第一次提示“无法打开”就右键 → 打开）。
     - **Windows**：双击 **双击安装.bat**。没装 Python 的先到 python.org 安装，安装时勾选 “Add python.exe to PATH”。
     它会自动导入“下载”文件夹里的团队配置。
3. 提示缺 FFmpeg：按它给的办法装好（Mac：`brew install ffmpeg`；Windows：`winget install Gyan.FFmpeg`），再装一次。看到“安装完成”就好了。

装好后你的电脑上会多一个 **买量工作台**（在你的个人文件夹里：Mac 是 `~/买量工作台`，Windows 是 `C:\Users\你的用户名\买量工作台`），桌面上多两个快捷方式：**今日待上传**、**买量看板**（今天进行到哪、今日完成、管线各项目走到哪个节点）：

| 文件夹 | 放什么 |
|---|---|
| `每日/今天日期/01_A段` | 你把今天的 A 段放这里 |
| `每日/今天日期/03_待上传` | Codex 出好的成片和上传清单（就是桌面的「今日待上传」） |
| `每日/今天日期/04_已上传` | 你回填素材 ID 后，Codex 把那条移到这里 |
| `每日/今天日期/作废` | 序号改用后退下来的旧版本，**不要上传** |
| `台账`、`配置`、`程序` | Codex 用的，不要动 |

以前用过旧版（桌面有 `待上传` 文件夹）的，安装时会自动搬进工作台：每个文件核对内容一致后才移走原件，不丢东西；和工作台里同名但内容不同的文件不搬，会提示你。

以后更新：对 Codex 说“更新交付包”；或在仓库目录里 `git pull` 后再双击安装一次。负责人发了新的团队配置，就放进“下载”文件夹再双击一次。

## 二、每次使用

### 1. 先在后台查今天的序号
在后台视频列表搜索「**今天日期 + 你的设计师码**」，例如 `261119D`。看今天你最大的序号是几，**＋1** 就是这次要用的序号（今天还没有就是 1）。

### 2. 对 Codex 说一句话（照着改就行）

```text
用 ab-join-name-upload 帮我接B出清单：A 段标题「AI海上找清静鸣人」，主推角色鸣人。我是 D，今天从序号 5 开始，需求人原创。
```

- A 段放在今天的 `01_A段` 里就不用说路径；放在别处就加一句“A 段是 /路径/A段.mp4”。
- 有需求人就把“原创”换成需求人代号；有实习生参与就加一句“实习生 HP”。
- 默认是 火影／忍界大战／小剧场／AI／SD2拼框。不是 AI 素材就说“非 AI”。

### 3. Codex 做完后
打开桌面的 **今日待上传**：
- 3 个成片：已经按正式名称命名好了；
- 每个成片配一份 `……上传清单.md`：后台每一栏填什么都写好了；
- 一份 `本次待上传_…md` 总表：3 条各接了哪段 B、为什么选它。

### 4. 上传（每条都这样）
1. **完整看一遍成片**：接点、片尾、字幕、声音。
2. 后台再搜一次序号，确认没被别人占；被占了就告诉 Codex“序号被占了，从 6 开始重出”。
3. 打开“新增视频”，**先填名称和所有字段，最后再选文件**。选文件就会开始上传，填错了改不了。
4. 入库后把素材 ID 告诉 Codex，比如“D5 的素材 ID 是 124887”，它会记进台账，并把这条移到 `04_已上传`。

## 三、命名规则（Codex 会自动按这个来）

`日期 设计师码 序号 - A段标题接B段标题 - 需求人代号或原创 [- 实习生代号] [- 37]`

例：`261118LW3-AI偏心生日被毁鼬接首充开鼬-LW-37`

- **-37**：这段 B 是别人做的。你拿 3 份，做 B 的人（第二设计师）拿 7 份。B 是你自己做的就没有 -37。
- **没有需求人**：名称里写“原创”，后台“需求人”选**你自己**（上传清单里已经写好）。
- **第二设计师**：按选B台登记的“实际做这段 B 的人”填，不是看 B 段名字开头的代码。
- 序号按人、按天重置。

## 四、遇到问题

| Codex 说 | 怎么办 |
|---|---|
| 连不上选B台 | 选B台地址可能变了，找负责人要新地址，再对 Codex 说“选B台地址改成 ……”。 |
| 第二设计师未登记 | 这段 B 还没登记是谁做的，Codex 会自动跳过。想用它，请负责人先补登记。 |
| 不在可选项里 | 代号、角色或字段在后台下拉里找不到，请负责人更新字段表。 |
| 序号已上传为…… | 这个序号你已经用过了，换下一个序号。 |
| A 段不在 10–25 秒 | 只是提醒，可以继续。 |

账号、密码、验证码只在你自己的浏览器里输入，**不要发给 Codex**。
