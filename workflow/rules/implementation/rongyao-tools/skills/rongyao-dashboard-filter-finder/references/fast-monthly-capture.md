# 月度消耗快速路径

日期示例仅说明格式；实时操作必须传 --material-range 指定当前已确认的完整产出范围。历史控制值不随包迁移，没有本次校准输入时 calibration.passed=null。

## 目标

把多月抓取消耗压缩为一次初始化和每月一次查询。后台响应时间之外，不重复扫描筛选表、超长选项或素材明细。

## 速度优先级

1. 复用已登录且已打开的 `adopenplatformSource` 标签页。
2. 首月执行一次完整口径指纹核验；后续月份只核验日期、`gid=193`、`date_group=tenyear` 和查询会话刷新信号。
3. 优先使用浏览器的定向 DOM 定位；只读取需要的控件和汇总行，不读取整页正文或完整无障碍树。
4. 浏览器连接或标签接管超时后先判断查询是否已经提交；提交后只允许一次结果读取恢复，不能切换通道重发查询。

## 稳定目标

优先按页面实际 DOM 核验以下目标：

```text
日期值        #_1_search_date
母游戏        #_1_search_gid
日期汇总      #_1_search_date_group
查询按钮      input.btn.btn-primary[type="button"][value="查询"]
结果表        table.tablesorter
刷新会话      input[name*="rand_num"] 或页面等价 rand 字段
```

选择器失效时从一次最新 DOM 快照重建；不要用猜测选择器反复超时。

## 日期最快设置法

1. 点击当前日期范围按钮。
2. 找到日期面板内的开始和结束两个可编辑输入框。
3. 直接写入目标月 `YYYY/MM/01` 与 `YYYY/MM/DD`。
4. 点击“确定”，核验顶部日期范围完全一致。

仅在输入框无法写入或控件未提交时使用日历：

- 每次打开面板后先观察左右月份；日期面板可能保留上次浏览月份，不能根据当前查询月份猜测面板月份。
- 不复用跨月份坐标；先确认目标月份在哪一侧，再点击 1 日和末日。
- “本月/上月”只用于它们确实对应请求月份时，不用于历史月份猜测。

## 一次初始化

首月只做一次：

1. 核验 `gid=193`、完整标签/子游戏/系统/渠道/负责人/产品全选状态和其余固定口径。
2. 记录固定筛选指纹；保存当前查询会话 `rand_before`。
3. 定位结果表表头 `花费` 的列序号及 `总计` 行。

之后不得重复展开相同子游戏、母渠道、负责人或产品选项，除非页面显示依赖列表被重新加载或筛选指纹发生变化。

## 批量月份循环

对月份队列依次执行：

```text
设置自然月起止日期
→ 核验顶部日期
→ 记录 rand_before
→ 点击一次查询
→ 等待 rand_after != rand_before
→ 读取总计行的花费和总条数
→ 记录月份、日期、花费、rand_after
```

必须串行查询，避免并发请求覆盖页面最近查询会话和导出 `rand`。

## 定向读取总计

不要读取全部素材行。只需：

1. 从结果表第一行读取表头并找到 `花费` 列。
2. 找到第一条标签为 `总计` 的汇总行。
3. 读取该行 `花费` 列的纯数字值。

若无障碍文本夹入协作者姓名等覆盖文字，以表格列结构或截图中的汇总行数值为准，不把姓名当数据，也不把后一列“计划数”误作花费。

## 刷新完成门禁

满足下列条件后才确认月份：

- 顶部日期等于目标自然月；
- `gid=193` 且 `date_group=tenyear`；
- 查询会话 `rand` 已变化；若页面不可读取 `rand`，则总条数或汇总行已完成一次刷新并稳定；
- `总计→花费` 是可解析的非负整数。

日期变化但 `rand`、总条数和总计仍保持旧状态时，只等待结果，不重设所有筛选。

## 通道降级规则

- 浏览器定向控制：一次连接/标签接管失败后停止重试。
- 桌面交互：保持荣耀后台标签页为当前页；若用户切换标签，先从标签列表重新定位 `mayi数据后台`，禁止继续使用旧元素编号或旧坐标。
- 桌面读取只获取一次完整状态以建立索引，之后用日期按钮、查询按钮和汇总行的小范围状态；不要每月读取数千个素材节点。
- 后台未登录或权限失效时停止，不改用归档数字。

## 预期节奏

后台正常响应且页面未被切走时：首月完成口径校准，后续每月只承担一次日期设置、一次查询和一次汇总读取。时间主要由后台查询决定，而不是由筛选扫描或日历操作决定。
