# 导出与筛选字段地图

日期示例仅说明格式；实时操作必须传 --material-range 指定当前已确认的完整产出范围。历史控制值不随包迁移，没有本次校准输入时 calibration.passed=null。

## 导出机制

- 页面：`adopenplatformSource`。
- 按钮：`export`，显示名“导出”。
- 前端动作：`ac=export&rand={rand}`，直接复用最近一次成功查询会话，无导出配置弹窗。
- 新查询带 `search[submit]=1`，后端生成新 `info.rand`；成功回调同时更新 `rand` 和 `search.rand_num`。
- 翻页、排序复用当前会话。切换查询条件后必须先点“查询”，否则导出的是旧会话。
- 前端未声明文件扩展名；不得声称一定是 CSV/XLS/XLSX。

## 原生导出兼容路径

普通火影素材CSV导出使用主Skill的统一 `export` 命令，与分析共用抓取流程。只有需要当前页面的特殊筛选、额外列或后台原生下载文件时，才使用本节；不能先运行普通导出再在此重查。

### 一次查询后导出

1. 把用户目的规范化为日期、项目、汇总方式、汇总维度、标签和额外列。
2. 复用当前已正确的筛选，只修改差异字段。
3. 按依赖顺序设置所有筛选，最后只查询一次。
4. 等待表格总计和条数刷新；旧总计仍存在时不得导出。
5. 用户明确要求导出时，点击唯一“导出”按钮一次；出现浏览器下载权限提示时按浏览器安全规则处理。

先生成稳定契约可避免重复扫描：

```bash
python3 scripts/build_export_contract.py \
  --start-date 2026-06-01 \
  --end-date 2026-06-30 \
  --date-group tenyear \
  --group mid \
  --extra-column pcids
```

只做导出预检时，运行统一只读查询并核验返回的 `export_preflight.ready=true`、日期、项目和筛选身份；这不会下载文件。普通素材CSV直接使用主Skill的 `export`，不要先做一次预检查询再另跑导出。特殊筛选的原生下载应复用已核验的同一次查询 `rand`；先确认该入口支持全部筛选，不把固定素材维度CLI用于它未支持的条件。

## 筛选字段

### 时间与项目

| key | 显示名 | 类型 | 依赖/说明 |
|---|---|---|---|
| `date` | 日期 | 日期范围 | 数据发生日期 |
| `date2` | 素材产出 | 日期范围 | 素材产出日期；素材产出数量任务保留本次确认的全范围（用 --material-range 显式传入），不按目标月筛选 |
| `gid` | 母游戏 | 多选 | 火影=`忍界大战(193)` |
| `category` | 标签 | 多选 | 依赖 `gid` |
| `pkid` | 子游戏 | 多选 | 依赖 `gid` |

火影 `gid=193` 当前标签映射：`133=微信小游戏`、`145=ios包`、`146=运营`、`147=安卓APP`、`148=直播`、`163=云抖小`、`165=字节小游戏`、`166=对外联运`。标签列表会随后台变化，运行时仍要核验。

### 投放范围

|---|---|---|
| `osid` | 客户端 | `""=全部`、`1=安卓`、`2=IOS` |

| `operation_client` | 系统 | `1=信息流`、`2=微信小游戏`、`3=字节小游戏`、`4=快手小游戏`、`5=b站小游戏`、`6=硬核渠道`、`7=鸿蒙`、`8=直播` |

### 汇总与文本

| key | 显示名 | 值 |
|---|---|---|
| `date_group` | 日期汇总 | `day=日`、`week=周`、`month=月`、`quarter=季`、`tenyear=区间汇总2` |
| `group` | 汇总维度 | `mid=素材维度`、`material_serial_number=素材编号`、`demand_name=需求人`、`design_name=设计师`、`source_type=一类`、`source_direction=二类`、`region_type=第二设计师`、`source_ip=ip`、`role=角色` |

| `start_cost` | 起始金额 | 默认 0 |
| `end_cost` | 结束金额 | 默认 999999999 |

- `role`（角色）是跨游戏静态大列表。火影常用候选包括：`佐井`、`佐助`、`佩恩`、`兜`、`凯`、`博人`、`卡卡西`、`大蛇丸`、`宇智波鼬`、`小佐助`、`小南`、`小李`、`小樱`、`带土`、`斑`、`木叶丸`、`柱间`、`水门`、`照美冥`、`纲手`、`群角`、`自来也`、`辉夜`、`迪达拉`、`雏田`、`鸣人`、`鹿丸`。只按用户点名选择，不自动套用。
- `region_type`（第二设计师）是动态大列表，不缓存人员值。

### 类型与过滤

| key | 显示名 | 值 |
|---|---|---|
| `source_video_type` | 类型 | `""=全部`、`1=视频`、`2=图片`、`3=图文` |
| `record_type` | 数据维度 | `1=活跃`、`2=注册`、`3=新注册` |
| `aweme_id` | 主播 | 动态列表 |
| `big_aweme_id` | 自定义主播 | 动态列表 |
| `filter` | 过滤数据 | `1=是`、`0=否` |
| `weekday` | 星期 | `""=全部`、`1..7=星期1..星期7` |
| `custom_list` | 自定义 | `clickCount=点击`、`pcids=母渠道`、`showCount=展示` |

“显示筛选信息”实际打开数值门槛构造器；支持消耗、ROI1～ROI7、2～7日倍率等条件，不是导出预览。

素材产出数量任务默认 `negative_keyword=""`，不排除 XG。只有用户明确点名排除词时才设置；月消耗任务仍按对应请求和控制指纹处理。

## 表格与导出字段认知

表格配置包含：收藏、日期、素材、素材编号、日表、一类、二类、角色、母渠道、产出日期、需求人、设计师、第二设计师、花费、计划数、0消计划数、素材数、达标素材数、达标素材率、CTR、eCPM、注册、转化率、CPA、新付费数、CPP、CPP+、付费率、新付费、ROI1～ROI7、2日倍率、7日倍率、至今回本率、次留、付费次留、CVR、25%完播、100%完播、展示、点击。

默认隐藏字段：素材编号、展示、点击。前端隐藏不等于导出文件一定排除；未实际下载核验前不要推断导出列。

## 动态列表与速度策略

- `category/pkid` 在 `gid` 改变后重载；`pcid` 在系统改变后重载；`accountId` 在母渠道改变后懒加载。
- 动态列表不要写死。当前观察到：母游戏 87、火影子游戏 141、母渠道 93、负责人 49、产品 194、设计师/需求人各 46、主播 203、自定义主播 294 个选项。
- 当前目标值已正确且依赖选项存在时直接复用；不要重复展开超长下拉。
- 多选中的“全选”会把具体值序列化进查询。不得把“全部已选”误判为空数组。
