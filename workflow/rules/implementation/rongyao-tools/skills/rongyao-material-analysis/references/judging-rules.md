# 素材判断规则

先按 [evidence-boundaries.md](evidence-boundaries.md) 区分指标、后台标签、名称、内容和建议。指标达标支持效果结论，具体表达机制需内容依据；新增创意标 `generated_proposal`、`validated=false`。

## 判断顺序

1. 固定实际项目、双日期、阈值来源、完整性和成熟度。
2. 区分产出、有消耗、可观察、有付费、有效五种数量；新老身份结合历史记录核对。
3. 查看消耗量级、付费数/成本、ROI1和ROI2各自表现；不以单指标替所有效果。
4. 有可比上期时描述变化，拆解新老贡献、头部集中与其余素材表现。
5. 内容已核验时比较实际角色、剧情、A/B段和卖点组合；需要制作建议时再提出假设或对照。

## 常见结论的证据

| 结论 | 必要证据 |
| --- | --- |
| 当期消耗上升 | 同项目、同筛选、等长紧邻两期的消耗 |
| 付费量增加 | 同口径新付费数比较；不自动等于ROI或成本改善 |
| 付费表现变弱 | 分别说明ROI、付费成本、达标率等实际恶化指标；只有单项变化时只描述该项 |
| 老素材支撑消耗 | 新老分组消耗贡献及分母；有效贡献须另算 |
| 新素材接替有效贡献 | 新老身份、完整有效规则、有效素材和贡献的两期比较 |
| 仅N条有付费 | 指定范围内 `新付费数>0` 的去重条数；不是观察素材或达标条数 |
| 老素材复测有效 | 当前复测数据满足本次确认的完整有效规则；只有消耗时写重新起量 |
| 结构可复用 | 同一内容变量在多条可观察素材中复现，内容来源可核对，兼顾反例 |

样本少时缩小外推范围；完整聚合数据仍可支持方向量级描述。没有可比基线时描述当期贡献，不编趋势。历史窗口无匹配只写“本次口径未检出”。

## 层级与代表素材

单素材的结果保持单素材范围。方向聚合描述、结构复用、增加产量/预算分别判断；多条效果复现加内容证据才支持结构判断。某方向仅由一条头部拉动时明确集中程度和其他素材状态。

代表素材选择为解释变化、复现或反例，不机械选排序最高。引用准确名称、必要指标和选择理由。内容未看时只描述数据和名称事实；不强制解释“为什么理解成本更低”。同一B段、同一角色可形成比较维度，剧情系列的划分需要故事内容一致。

角色、画风、关系冲突、技能展示、攻略或福利卖点都可作为变量；以本次实际素材为准。原因未知时记录竞争解释，不自动套“保留A换B”或“补引流”。具体对照建议只在用户需要时填写 `next_test`，纯效果结论为 null。
