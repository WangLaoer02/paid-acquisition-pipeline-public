# 成品周报兼容路由

用户要正式周报时，检查目标环境是否有 `rongyao-weekly-report-writing`（从当前环境已安装Skill目录按名称读取），然后传入已校验数据、`analysis_findings`、当前文档和本次业务周期。不要在本文件复制第二套总览、字段或五类计划模板。

成品固定顺序为产出与创新、测试及有效统计、两个较优方向与方向图、方向表现、标签图与细分结论、下周计划。最新用户文档的栏目和删改优先；具体句式、版式及方向论述方法从上述写作 Skill 入口按其实际引用读取，不在独立分析套件中假定成稿依赖已安装。

写作 Skill 未安装时仍完成本 Skill 的专项 finding，明确缺少成稿能力；不假装调用。本套无凭据迁移包不包含写作 Skill，完整周报环境需单独安装其文件及飞书文档能力。判断方法见 [report-logic.md](report-logic.md)，具体输出示例见 [examples.md](examples.md)。
