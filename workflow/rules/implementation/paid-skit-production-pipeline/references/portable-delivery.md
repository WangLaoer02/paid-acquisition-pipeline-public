# 工程素材路径与搬移核对

适用：收集Premiere素材、制作交付包、迁移工程或排查本机正常而异地离线。先读取当前保存工程与目标包清单，本机续编工程和交付快照分开，媒体数量按实际工程引用，不固定案例套数。

1. 从真实工程解析引用，保留媒体身份、源路径和实际SHA；按清单将使用及需保留的完整原片/备选收集到包内。额外剧本与来源文件注明不属于新增采用剪辑。文件存在与同名不足以证明版本正确；校验媒体字节，ZIP还需CRC与唯一交付工程检查。
2. 核对每个媒体节点实际使用的路径字段。Premiere工程可同时出现大小写不同的 `relativePath`、`RelativePath` 与 `FilePath`；修改其中一个不证明其余已经迁移。逐项区分包内相对引用、本机绝对引用、历史缓存/查找路径，按实际节点归属检查。能在原工作区解析的旧路径仍可能是异地依赖。
3. 修复前保存原工程与包哈希，在独立候选最小修改受影响路径；维持媒体节点身份，不按同名重导入媒体或重建剪辑。对比路径以外的XML/编辑语义：一个主序列、轨道和静音、采用素材、入出点、转场、字幕及Source In/Out均保持。写回原包或归档前再次核对源哈希，源变更则重新读取。
4. 重新解析候选，逐项把相对路径按包根解析，检查存在且SHA与清单一致。搬移模拟须禁用原工作区路径，按另一个根解析或在临时位置重连实际包内文件；用本机仍可访问的绝对路径不能证明可搬移。单纯路径解析模拟标MOCK，不认证另一台设备已打开。
5. 条件允许时在PR原生打开独立包、检查媒体在线及主序列，保存后回读实际路径；保护用户原工程与未保存修改。原生打开证据必须指向这份修复工程的实际SHA，旧工程已打开的回执不传播给新候选。不能安全打开时保留待验，提供明确从包内素材目录重连的方式，不宣称自动重连或零外部依赖。

原生打开、可见画面样本与全部媒体在线分计。用离线查询判断时，先回读查询范围、各条件字段和实际输入，再取得查询确已执行及结果状态；只有控件已填、无弹窗或未出现结果不能写零离线。输入动作返回成功但值未改变时，改用工具文档支持的输入方式并回读，不沿用未生效条件。结果或全项目范围无法证明就保持全量在线待验。
6. 交付说明分别标媒体收齐/字节核对、路径解析、模拟搬移、原生打开、异机验证和声音验收。未带字体或其他插件依赖时注明实际依赖。未改变剪辑的路径修复不要求重生视频；是否需新原生导出由实际剪辑或渲染变化决定。
